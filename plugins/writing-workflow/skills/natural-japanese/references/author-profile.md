# Optional author profile

Read when `style-profile.md` exists in the target project root or the user's
specified location, or when the user asks to learn the author's style. Without
a profile, use the general guidance in [the skill](../SKILL.md). The profile is
optional and never overrides source preservation.

Only when asked to learn the author's style, extract tendencies from three to
five prior pieces using [the profile template](../assets/style-profile-template.md).
Describe tendencies, not certainties. Record author-rejected expressions with
their source and scope; prohibit only the specific combination, not the whole
word or its use by everyone. Do not create a profile automatically. Leave an
author profile in the user's project only when explicitly requested.
