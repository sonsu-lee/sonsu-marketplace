# Sources

The [Superpowers TDD skill][skill] and [Writing Good Tests][good] are from
`obra/superpowers` at revision `22f0b463e7a5e579904dd6211a520321035526f7`.
See [THIRD-PARTY-LICENSES](THIRD-PARTY-LICENSES) for Jesse Vincent's MIT notice.

- [SKILL.md](skills/test-driven-development/SKILL.md) keeps the upstream
  red-green-refactor cycle, verification points, checklist, debugging
  integration, and final rule. Before RED, the user approves the observable
  test contract and the reuse or extension of existing coverage. An approved
  plan supplies that approval. Host permissions and verification assignments
  govern runs, suite scope, and code removal.
- [Worked cycles][cycles] preserves the upstream graph, sample code, good-test
  table, and empty-email example outside the entry file to fit the Codex skill
  prompt limit. The retry test name matches its actual attempts, and the form
  example uses a focused test command.
- [Common rationalizations][flags] preserves the upstream table and stop signs
  as a conditional reference. Starting over does not authorize deletion of
  existing work.
- [Writing Good Tests][local-good] retains the upstream companion file and its
  relative path. It uses the consuming host for behavioral skill checks instead
  of assuming another upstream skill is installed. Descriptive headings
  distinguish the two gate functions.
