# 상위 티켓

> 영문 정본: [parent.md](parent.md) (`a482860` 기준 번역).
> 사람이 읽기 위한 번역본이며 에이전트는 이 파일을 읽지 않는다.

요청이 우선순위를 정하거나 미루거나 독립적으로 끝낼 수 있는 여러 부분에
걸쳐 있을 때, 또는 상위 티켓, 에픽, 트래커 프로젝트를 만들거나 수정하거나
쪼갤 때 읽는다. 어떤 네이티브 컨테이너를 쓸지는 플랫폼 참조 문서가 정한다.

## 상위 티켓이 필요한지 판단하기

공유된 목표가 보이는 상태로 개별 하위 티켓이 진행되어야 할 때만 상위 티켓을
쓴다. 작은 변경은 티켓 하나로 둔다. 하위 티켓이 하나뿐인 상위 티켓이나, 한
사람이 함께 끝내는 단계를 하위 티켓으로 만들지 않는다. 코드, 필요한 테스트,
필수 문서는 같은 티켓에 둔다.

맥락이 뒷받침하지 못하는 분해를 지어내지 않는다. 문제는 알지만 접근법이
아직 열려 있다면, 짐작한 구현 하위 티켓을 나열하지 말고 열린 질문을 조사용
하위 티켓이나 미해결 질문으로 눈에 보이게 둔다.

## 상위 티켓 쓰기

공유되는 합의는 상위 티켓에 두어 하위 티켓이 반복하지 않게 한다.

- **문제:** 현재 상황과 그것이 왜 중요한지. 현재 상태가 왜 실패하는지
  보여 주는 구체적인 사례 하나에 근거하는 것이 좋다.
- **원하는 결과:** 여러 부분이 함께 작동할 때 관찰되는 결과. 변경을 전달하는
  것과 그 효과를 나중에 평가하는 것이 둘 다 중요하다면 구분한다.
- **제외 사항:** 합리적인 담당자라면 달리 포함했을 작업만 쓴다. 문제가
  끌어들이는 인접 기능 같은 것이다. 아무도 시도하지 않을 일은 나열하지
  않는다. 알려진 시간이나 노력의 한도는 확립된 경우에만 기록하고, 지어내지
  않는다.
- **순서:** 트래커가 보여 주지 않는 하위 티켓 사이의 의존성이며, 없으면
  생략한다. 같은 상위 티켓 아래에 있다고 해서 순서가 있다는 뜻은 아니다.
  하위 이슈처럼 트래커가 기본으로 보여 주는 하위 목록을 반복하지 않는다.
  초안은 제안하는 분할을 상위 티켓 본문 밖에서 제시한다.
- **맥락:** 결정, 설계, 증거. 복사하지 말고 링크한다.

하위 티켓이 모두 닫혔다고 해서 상위 티켓이 완료된 것은 아니다. 통합, 롤아웃,
종단 간 검증이 결과의 일부라면 명시한다. 트래커가 상위 티켓을 자동으로
닫는다면 그것을 별도의 하위 티켓으로 만든다.

## 하위 티켓 쓰기

각 하위 티켓에 고유한 문제와 판단 가능한 결과를 준다. 공유 정책은 상위
티켓을 링크하고, 안전하게 행동하는 데 필요한 로컬 제약만 남기며 전체
명세는 옮기지 않는다. 각 요구 사항은 소유하는 티켓이 하나여야 한다. 하위
티켓이 취소되면 그 요구 사항이 제거되었는지, 대체되었는지, 옮겨졌는지를
상위 티켓에 기록한다.
