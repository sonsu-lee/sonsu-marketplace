# 모바일 앱 환경

iOS·Android와 사용 중인 framework·컴포넌트를 확인한다. 앱의 탐색·입력·시스템 동작에 관한
구체적인 선택은 대상 버전의 공식 Apple HIG 또는 Android/Material 문서와 기존 프로젝트에 대조한다.
웹 화면을 줄여서 모바일 설계를 대신하지 않는다.

- 탐색 계층·탭·뒤로 가기·dismiss·modal을 기존 앱과 플랫폼 의미에 맞춘다.
- 터치 영역, 시스템 영역·inset, 소프트 키보드가 입력·오류·제출을 가리는지 확인한다.
- 화면 회전·창 크기·글자 크기 변화와 필요한 태블릿/외부 키보드 입력을 고려한다.
- 권한 요청의 시점, 거부 후 다음 행동, 앱 중단·복귀·프로세스 재생성에서 보존할 상태를 정한다.
- offline·느린 연결·중복 실행·사진/스캔 취소는 해당 기능이 있을 때 다룬다.

Figma·이미지는 설계 범위의 증거다. 네이티브 구현은 기존 프로젝트의 검사와 시뮬레이터·에뮬레이터
또는 실제 기기의 대표 조작으로 확인한다. 브라우저 모바일 viewport만으로 네이티브 키보드·권한·
수명주기를 검증했다고 말하지 않는다. 환경이 없으면 구현과 검증 상태를 각각 보고한다.
새 앱 기반이나 framework를 이 스킬의 자동 선택만으로 생성·설치하지 않는다.
