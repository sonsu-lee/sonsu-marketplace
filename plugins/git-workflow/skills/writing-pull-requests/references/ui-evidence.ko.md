# UI 증거

> 영문 정본: [ui-evidence.md](ui-evidence.md) (`b57290e` 기준 번역).
> 사람이 읽기 위한 번역본이며 에이전트는 이 파일을 읽지 않는다.

리뷰어가 앱을 실행하지 않아도 바뀐 위치와 결과를 볼 수 있게 한다. 저장소의 증거
요구사항이 우선한다.

- 외형은 **스크린샷**, 상호작용·전환·타이밍은 **비디오**. 각각 다른 것을 보여 줄
  때만 둘 다 쓴다.
- 눈에 보이는 변경이 없을 때만 증거를 생략하고, 이유가 분명하지 않으면 적는다.

## 캡처

1. 의도한 리비전의 실제 앱이나 문서화된 미리보기를 안전한 테스트 데이터로
   실행한다. 목업이나 지어낸 이전 상태는 쓰지 않는다.
2. 기존 화면은 같은 조건의 Before와 After를 보여 준다. 새 화면은 After만 보여 줘도
   된다.
3. 스크린샷마다 바뀐 영역을 상자, 화살표, 번호로 표시하고 대체 텍스트와 짧은
   캡션을 단다.
4. 비디오는 시작 상태, 동작, 결과를 보여 준다. 리뷰 대상인 타이밍이나 순서를 잘라
   내지 않는다.

## 확인과 게시

1. 모든 이미지를 열고 모든 비디오를 재생한다. 리비전, 변경, 읽을 수 있는 표시를
   확인한다.
2. 자격 증명, 토큰, 개인정보, 고객 데이터가 없는지 확인한다.
3. 저장소가 요구하는 곳에, 없으면 PR 본문에 증거를 둔다. 업로드는
   [게시 절차](publishing.md)를 따른다.
4. 렌더링된 PR을 확인한다. UI가 바뀌면 증거도 갱신한다.

## 주의할 점

- 캡처, 표시, 업로드에 실패했다고 증거가 불필요해지지는 않는다. 빠진 것을 보고한다.
  Draft에 공백을 적을 수는 있지만 완료된 증거처럼 보여서는 안 된다.
- URL을 얻으려고 미디어를 커밋하지 않는다.
