# PR 상태 조회

지정 PR 하나 또는 요청한 저장소의 열린 PR을 읽기 전용으로 조회한다. 직접 호출이면 해당 선택을
우선하고 목적이 다르면 차이를 설명한다. 코드 수정이나 후속 복구를 자동 실행하지 않는다.

## 조회

1. [GitHub PR 조회](../../references/pr-inspection.md)로 host/repository/PR과 도구·인증을 확인한다.
   대상 생략은 현재 저장소로 해소하고, 여러 대상이 가능할 때만 질문한다.
2. 목록 요청은 전체 페이지를 수집하고 각 PR의 최신 개별 상태를 읽는다. 개수 제한을 전체
   목록으로 표현하지 않는다. 일부 실패는 확인한 범위와 누락을 보존한다.
3. Draft, base/head SHA, mergeStateStatus, check의 성공·실패·진행·미확인,
   reviewDecision과 리뷰별 commit, 미해결 review thread를 서로 다른 관찰로 기록한다.
4. 봇의 PR 본문 👍는 선택적 부가 정보다. 반응만으로 현재 head를 검토했다거나 CI·병합 조건을
   통과했다고 판정하지 않는다. 이전 commit의 리뷰와 현재 head의 리뷰도 구분한다.

## 보고

조회 시점·저장소·범위와 결과 수, 링크, Draft, head, 병합 상태, CI, 리뷰와 미해결 대화를 표로
제시한다. 목록에서는 요약하고 상세 근거는 필요한 PR에만 붙인다. check가 없음, 조회 실패,
pending, skipped/neutral을 성공으로 합치지 않는다. `CLEAN`이나 `UNSTABLE`은 관찰한 GitHub 상태이며
사용자 대신 내린 병합 승인이나 완전한 준비 판정이 아니다.

조회 중 head가 바뀌면 항목을 새 head 기준으로 갱신하거나 혼합 관찰임을 표시한다. GitHub의
여러 API를 읽는 것이 원자적 snapshot은 아니다. 실패한 조회를 빈 결과로 보고하지 않는다.
