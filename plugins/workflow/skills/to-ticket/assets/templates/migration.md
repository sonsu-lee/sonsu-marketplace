# 데이터·schema·환경 전환 — `migration`

## 선택과 준비 상태

기존 상태에서 목표 상태로 이동하면서 데이터·호환성·운영 제약을 지켜야 할 때 선택한다.

- 접수 최소 정보: 이전 대상·목표 상태·전환 이유가 있으면 접수한다.
- 실행 준비: 전환 범위·보존 속성·호환성·cutover·복구 조건과 완료 판정이 확인되어야 한다. 되돌릴 수 없다면 합의된 대체 복구 경계를 보존한다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 전환 대상과 목표 상태
<현재 상태·목표 상태·포함 범위>

## 보존 조건과 전환 제약
<데이터 정합성·소비자 호환성·승인된 순서·cutover 조건>

## 복구 조건
<rollback 또는 대체 복구 경계와 확인된 제한>

## 완료 조건
- <목표 상태·보존 속성·필요한 이전 경로 정리 조건>
```

## 종료와 다음 관계

전환 대상과 보존 조건, 요구된 정리 결과를 확인한다. 일부 대상만 전환된 상태를 전체 완료로 표현하지 않는다.

호환 준비·데이터 전환·구 경로 제거가 독립 결과이면 parent/child와 실제 dependency를 사용한다. 고정 단계나 자식 수를 만들지 않는다.
