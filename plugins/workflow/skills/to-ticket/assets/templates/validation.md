# 독립 검증·QA — `validation`

## 선택과 준비 상태

정해진 결과·품질 기준에 대한 검증 판정 자체를 독립적으로 추적할 때 선택한다.

- 접수 최소 정보: 검증할 대상과 확인하려는 질문이 있으면 접수한다.
- 실행 준비: 대상 revision·환경·범위와 판정 기준, 필요한 증거가 정해져야 한다. 구체적인 테스트 도구·명령은 승인 제약이 없으면 작업자가 정한다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 검증 대상과 기준
<대상 버전·환경·범위와 합의된 판정 기준>

## 필요한 증거
<판정을 뒷받침할 관찰 결과와 증거 범위>

## 판정과 한계
<실행 뒤 실제 결과·미검증 범위·실패 또는 판정 불가 이유>
```

## 종료와 다음 관계

검증 작업 종료와 대상의 기준 충족을 구분한다. 실패·판정 불가·미실행을 통과로 쓰지 않고 릴리스 조건 충족 여부를 따로 기록한다.

발견된 독립 결함은 bug에 연결한다. 단순 검증 종료만으로 부모 기능이나 rollout을 완료 처리하지 않는다.
