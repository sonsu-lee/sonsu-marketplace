# 조사·기술 검토 — `investigation`

## 선택과 준비 상태

답할 질문이나 불확실성 해소 자체가 결과일 때 선택한다. 구현 방법이 열려 있다는 이유만으로 별도 조사 티켓을 만들지 않는다.

- 접수 최소 정보: 답할 질문과 그 답이 필요한 후속 판단을 특정할 수 있으면 접수한다.
- 실행 준비: 조사 범위·필요한 근거·기대 산출물과 종료 조건이 정해져야 한다. timebox가 이미 합의됐다면 보존한다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 답할 질문
<불확실성과 이 답이 필요한 결정>

## 필요한 근거와 산출물
<판단에 필요한 증거·비교·결론 기록>

## 종료 조건
- <답해야 할 질문과 근거 수준. 답을 낼 수 없는 경우의 한계 기록 조건>
```

## 종료와 다음 관계

근거 있는 답 또는 확인된 한계·남은 질문을 남긴다. 조사를 수행했다는 사실을 질문이 해소됐다는 결론으로 바꾸지 않는다.

결론은 같은 목적의 티켓에 보강한다. 별도 구현 결과가 승인되면 연결하고 그 답이 필수일 때만 blocked-by를 사용한다.
