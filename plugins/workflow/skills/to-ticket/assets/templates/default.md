# 일반 작업 양식

[티켓 작성 지침](../../references/ticket-writing.md)에 따라 아래 내용을 전달한다. 제목은 서로 다른 내용을 찾아 읽는 데 도움이 될 때 사용하는 배치 예시이며 필수 출력 구조가 아니다.

```markdown
## 배경·목적
<!-- 현재 문제·필요와 누구에게 어떤 영향이 있는지 설명합니다. -->

## 원하는 결과
<!-- 작업 뒤 무엇을 할 수 있어야 하거나 어떤 상태가 달라져야 하는지 설명합니다.
합의된 수용 조건도 여기서 한 번 적고, 서로 다른 실패를 구분할 때만 목록으로 나눕니다. -->

## 방향·맥락
<!-- 구현할 때 알아야 할 기존 동작·제약·합의된 선택 기준과 이유를 설명합니다.
결과를 판단하는 데 필요한 미정 사항과 관련 출처·자료도 해당 설명에 연결합니다. -->
```
