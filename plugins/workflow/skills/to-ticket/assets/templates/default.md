# 일반 작업 양식

기능 추가, 개선, 리팩터링, 문서 작성 등 변경·추가·정리 요청에 사용한다. 필수 여부와 주석은 작성 안내이며, 완성된 초안에서는 안내와 빈 선택 항목을 제거한다.

```markdown
## 문제
<!-- 필수: 지금 무엇이 문제인지와 알고 있는 영향을 설명합니다. -->

## 원하는 결과
<!-- 필수: 해결된 뒤 무엇이 달라져 있어야 하는지 설명합니다.
구현 방법, 작업 순서와 PR 분할은 이미 합의된 제약이 아니라면 담당자가 정하도록 둡니다. -->

## 참고
<!-- 조건부: 합의된 제약·범위, 사용자가 밝힌 선호, 외부 의존, 필요한 일정 정보나 관련 자료가 있을 때만 작성합니다.
필수 조건과 제안·선호를 구분하고, 링크·첨부에는 짧은 설명을 붙입니다. -->
```
