# 서비스·권한·지원 요청 — `service-request`

## 선택과 준비 상태

권한·계정·환경·지원 등 정해진 서비스 절차의 이행을 요청할 때 선택한다.

- 접수 최소 정보: 요청할 서비스·대상·필요한 결과가 있으면 접수한다. 불필요한 개인정보·credential은 수집하지 않는다.
- 실행 준비: 대상 범위·서비스 절차와 필요한 승인·수용 조건이 확인되어야 한다. 티켓 작성 권한은 실제 권한 부여나 계정 변경 권한이 아니다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 요청 내용과 대상
<필요한 서비스·범위·기대 결과>

## 처리 조건
<확인된 승인·정책·기간 등 이행 제약과 미해결 입력>

## 이행 확인
<제공된 결과와 수용 조건. 미이행이면 확인된 이유>
```

## 종료와 다음 관계

서비스 이행 결과 또는 정책에 따른 처리 결론을 기록한다. 접수·승인과 실제 제공을 구분한다.

제품 결함·새 기능 결정이 필요하면 해당 티켓에 연결한다. Jira Service Management의 request type은 실제 work type과 별도로 확인한다.
