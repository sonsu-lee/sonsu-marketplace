# 배포·단계적 공개 — `rollout`

## 선택과 준비 상태

구현 결과를 특정 환경·대상군에 제공하거나 feature flag를 전환하는 것이 독립 결과일 때 선택한다.

- 접수 최소 정보: 제공할 변경과 목표 환경·대상군이 특정되면 접수한다.
- 실행 준비: 진행·중단·복구를 판단할 승인 조건과 관찰 기준, 필요한 선행 결과가 확인되어야 한다. 단계·시간·담당자는 합의 근거가 있을 때만 고정한다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 제공 대상과 범위
<변경·환경·대상군과 선행 결과>

## 진행·중단·복구 조건
<승인된 공개 경계와 판단 조건, rollback 또는 forward recovery 제약>

## 완료 조건
- <목표 대상에 실제 제공된 상태와 필요한 운영 관찰>
```

## 종료와 다음 관계

목표 환경·대상군에 실제 제공되고 합의된 관찰 조건을 만족해야 한다. merge·배포 명령 성공만으로 대체하지 않는다.

같은 rollout의 단계는 한 티켓에 보강한다. 독립 release 결과만 분리하고 전체 기능의 완료 조건과 연결한다.
