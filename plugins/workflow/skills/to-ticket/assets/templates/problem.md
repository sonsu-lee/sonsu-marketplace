# 반복 장애·재발 방지 — `problem`

## 선택과 준비 상태

하나 이상의 incident를 넘는 원인·반복 패턴·재발 위험 관리가 주된 결과일 때 선택한다.

- 접수 최소 정보: 관련 incident·관찰 패턴 또는 원인에 관한 질문이 있으면 접수한다.
- 실행 준비: 해소할 원인 질문이나 합의된 예방 결과, 영향 범위와 종료·관리 판정 기준이 필요하다.

## 기본 본문

공통 작성 기준에 따라 단계에 필요한 section만 사용한다. 완료·판정 기록은 실제 결과가 있을 때 채운다.

```markdown
## 관련 장애와 반복 패턴
<관련 incident locator·반복 증거·영향>

## 원인과 미해결 질문
<확인된 원인과 검증되지 않은 가설을 구분>

## 예방 결과 또는 관리 결정
<합의된 개선 결과·우회책·남은 위험의 처리>

## 종료 조건
- <원인 규명·예방 결과 또는 승인된 관리 결정을 판정할 기준>
```

## 종료와 다음 관계

요청된 원인 질문·예방 결과 또는 승인된 관리 결정의 근거가 있어야 한다. 개별 장애가 복구됐다는 사실만으로 종료하지 않는다.

독립 구현 결과는 bug·maintenance 등에 연결한다. 회고 문서와 같은 내용을 복제하지 않고 근거를 링크한다.
