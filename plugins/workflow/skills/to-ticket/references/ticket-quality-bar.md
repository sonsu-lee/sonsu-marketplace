# 티켓 작성과 반영 검증

본문 구성, 기본 양식의 항목과 표현 기준은 번들 [티켓 작성 지침](ticket-writing.md)을 따른다. 이 문서는 실제 작성 입력, 출력 언어와 반영 결과를 확인한다.

## 작성 입력과 편집 범위를 확인한다

현재 요청과 확인한 티켓·자료를 기준으로 작성하고, 적용 양식·확인 상태·필수 필드와 편집 범위를 함께 전달한다. 기존 티켓의 부분 수정에서는 최신 전체 본문과 보존할 내용을 확보하고, 요청 밖의 내용이나 양식까지 교체하지 않는다.

초안을 선택한 양식의 필수 항목, 실제 필드와 대조한다. 확인되지 않은 정보와 필요한 입력을 표시하고, 양식 확인 실패를 양식 부재로 바꾸지 않는다. 임시 초안 작성은 게시 권한이나 원격 필수 필드 충족의 근거가 아니다.

## 출력 언어를 결정한다

티켓 언어는 사용자 지정, 대상 공간의 지침·양식·일관된 관례, 기존 티켓이나 승인 문서의 주 언어, 현재 대화 언어 순으로 정한다. 결과 보고는 사용자가 요청한 언어를 따른다. 고정된 양식 문구는 해당 양식이 허용할 때만 번역한다.

`writing:writing`이 있으면 결정된 언어와 편집 범위로 함께 적용한다. 해당 스킬이 없어도 번들 작성 지침으로 계속하며 자동 설치하지 않는다.

문체를 다듬은 뒤에도 고정 양식, 코드·식별자·링크·수치·의무 수준과 기존 결정이 보존됐는지 대조한다. 플랫폼이 해석하는 필드와 marker는 일반 설명문처럼 번역하거나 재작성하지 않는다.

## 결과를 정확히 기록한다

실제 결과가 생겼을 때만 본문에 보강한다. 접수·채택은 구현 완료가 아니며, 장애 복구는 재발 방지 완료가 아니다. 회고 작성과 후속 개선, 검증 수행과 기준 충족, 일부 대상의 전환과 전체 전환도 구분한다. 합의된 제공·복구·검증 조건을 충족했다는 근거 없이 완료로 표현하지 않는다.

본문의 결론은 원격 상태 변경 권한이 아니다. 실제 게시 결과와 준비한 초안을 구분하고, `not_run`·`unknown`을 성공으로 보고하지 않는다.
