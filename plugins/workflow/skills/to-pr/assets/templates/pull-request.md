# PR 기본 양식

적용 조건은 [PR 템플릿 규칙](../../references/pr-template.md#기본-템플릿-적용-조건을-확인한다)을 따른다. [PR 작성 지침](../../references/pr-writing.md)에 따라 이유·실제 변경·필요한 추가 맥락을 설명한다. 제목은 서로 다른 내용을 구분해 읽는 데 도움이 될 때만 사용하며, 짧은 문단이나 제목 없는 본문을 우선하지 않는다. 내용이 없는 제목을 채우려고 문장을 만들지 않는다.

| 의미 | 한국어 | English | 日本語 |
| --- | --- | --- | --- |
| 이유 | 이유 | Why | 理由 |
| 변경 관점과 결과 | 변경 | Changes | 変更 |
| 필요한 추가 맥락 | 참고 | Notes | 補足 |
| 여러 자료의 묶음 | 화면 자료 | Screenshots and videos | スクリーンショット・動画 |

```markdown
## <이유 제목>
<!-- 이번에 해결한 문제와 영향을 설명합니다. PR만 읽어도 변경이 필요한 이유를 이해할 수 있게 씁니다. -->

## <변경 제목>
<!-- 무엇이 어떻게 달라졌는지, 확인된 선택 이유가 어떻게 문제 해결로 이어지는지 설명합니다.
자료가 하나면 해당 설명 바로 뒤에 볼 지점의 caption과 첨부를 둡니다. -->

## <참고 제목>
<!-- 관련 요구 중 남은 일, 적용 제외 대상, 배포 선행 작업·복구 제약이나 중요한 미확인 동작을 해당할 때 설명합니다.
수용 여부를 판단하는 데 필요한 환경별 관찰·재현 조건은 PR 작성 지침의 검증 보고 기준에 따라 남깁니다. -->
```

여러 자료를 구분할 때만 화면 자료 제목을 사용할 수 있다. 확인된 `Part of`·`Closes` 등의 연결 줄은 [티켓 연결 규칙](../../references/ticket-linking.md)에 따라 본문에 한 번 남기며, 별도 관련 작업 섹션이나 티켓 요약을 만들지 않는다.

완성된 초안에서는 placeholder와 HTML 작성 안내를 제거한다. 필요한 자료가 없으면 검토에 중요한 미확보 사실만 본문에 남기고, 설치·캡처·검사 등 준비 조건은 본문 밖에 보고한다. 외부 고정 양식의 제목·순서·필수 항목에는 이 기본형의 정리 규칙을 적용하지 않는다.
