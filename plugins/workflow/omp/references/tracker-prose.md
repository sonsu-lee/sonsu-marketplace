# 티켓·PR·커밋 문장 형식

Workflow가 Writing 설치 여부와 관계없이 티켓·PR·커밋 문장에 적용하는 최소 규칙이다. 대상 공간의 양식과 필수 항목이 이 문서보다 우선한다.

## 경량형

- PR: 배경과 변경을 한 문단으로 설명할 수 있고 조건부 항목이 모두 비어 있으면, 제목(heading) 없이 그 문단만 쓴다.
- 티켓: 기본형에서 필수 항목 하나만 채워지고 조건부 항목이 모두 비어 있으면, 제목 없이 본문만 쓴다.

길이나 줄 수 같은 숫자 기준은 두지 않는다. 대상 공간의 양식이 제목을 요구하면 양식을 따른다.

## 서식 밀도와 어조

- 불릿은 같은 종류의 항목을 나열할 때만 쓴다. 굵은 글씨·이모지·체크박스는 양식이 요구할 때만 쓴다.
- "This PR …", "이 PR은 …", "本PRでは…" 같은 서두를 쓰지 않는다. 요약형 결말, 리듬을 맞추려고 셋씩 묶는 나열, 제목을 다시 말하는 첫 문장도 쓰지 않는다.
- 대상 공간의 최근 티켓·PR이 쓰는 서식 밀도에 맞춘다.
- 어조는 한 문서에서 하나로 통일한다. 대상 공간 관례를 따르고, 관례가 없으면 한국어는 합쇼체, 일본어는 です・ます로 쓴다.

## 제목

- 버그: "조건 + 관찰된 동작 + 대상"
- 작업: "대상 + 달라질 상태"
- tracker에 type 필드가 있으면 `[Bug]` 같은 접두를 붙이지 않는다.

## AI 사용 표기

[커밋 메시지 기준의 AI 사용 표기](commit-message.md#ai-사용-표기)를 따른다. 티켓·PR 본문에도 같은 기준을 적용한다.

## 예시

다음은 모두 이 저장소의 기준을 설명하려고 만든 로컬 예시다.

티켓 제목:

| before | after |
| --- | --- |
| 로그인 오류 | 세션 만료 후 새로고침하면 로그인 화면이 빈 페이지로 표시됨 |
| [Bug] 업로드 안 됨 | 10MB 넘는 이미지를 올리면 업로드 진행률이 0%에서 멈춤 |
| 알림 설정 개선 | 알림 설정에서 채널별로 수신 여부를 끌 수 있음 |

영어 경량형 PR 본문:

```markdown
The date picker in the export dialog showed the previous day for users in UTC+ time zones because it parsed the stored date as UTC midnight. It now parses the value as a local date, so the selected day matches what was saved.
```

한국어 경량형 티켓 본문:

```markdown
설정 화면의 언어를 일본어로 바꾼 뒤 앱을 다시 열면 영어로 돌아갑니다. 다시 열어도 마지막으로 고른 언어가 유지되어야 합니다.
```
