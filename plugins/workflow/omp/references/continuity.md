# omp の作業継続

複数段階の作業は omp 標準の todo とセッション履歴で管理する。現在の目的、承認済みの範囲、完了した作業、次の操作、未確認の結果を必要な範囲で残す。単発の作業や委任された部分作業のために別の記録を作らない。

コンパクションや再開後は、最新のユーザー指示、実際の成果物と外部状態を確認してから続ける。履歴や todo の完了表示だけで成功を判断しない。外部操作の結果が不明なら、同じ操作を繰り返す前に対象を読み直す。

このパッケージは独自の checkpoint、`.sonsu` 配下の記録、Git exclude、セッション hook、extension を作成・更新しない。既存の記録は削除・移行しない。標準の todo が使えない場合も、会話で確認済みの状態と次の操作を明示し、独自の保存先を追加しない。

作業の継続は実行権限を追加しない。読み取り専用の依頼を維持し、commit、push、PR・チケットの作成や更新などは各スキルの権限条件と現在のユーザー指示に従う。デザイン品質の成果物・検証は作業継続用の記録とは別に、対象スキルの契約に従う。
