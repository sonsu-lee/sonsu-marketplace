# 버그 양식

잘못된 동작을 수정하는 요청에 사용한다. 원인 조사가 필요한 수정도 이 양식으로 작성한다. 완성된 초안에서는 작성 안내와 빈 선택 항목을 제거한다.

```markdown
## 현상
<!-- 필수: 실제 동작, 기대 동작과 알고 있는 영향을 설명합니다.
기대 동작이 미정이면 결정이 필요하다는 사실을 적습니다. -->

<관찰된 동작과 발생 상황>

<기대 동작 또는 아직 정하지 못한 내용>

## 재현 정보
<!-- 조건부: 확인된 환경·시작 상태·재현 단계와 문제를 보여 주는 이미지·영상·로그·요청·응답을 필요한 만큼 적습니다.
자료가 어느 현상을 보여 주는지 설명하고 비밀·개인정보를 제거합니다. 순서가 중요한 경우에만 번호 목록을 사용합니다. -->

## 참고
<!-- 조건부: 현상과 재현 정보에 없는 합의된 제약, 외부 의존, 필요한 미확인 사항과 관련 근거만 적습니다.
반드시 지킬 조건과 제안·선호를 구분하고 링크·첨부에 짧은 설명을 붙입니다. -->
```

확인하지 않은 환경·단계·자료를 만들지 않는다. 자료가 없다는 사실이 작업 착수나 재현 판단에 중요할 때만 `참고`에 짧게 남긴다.
