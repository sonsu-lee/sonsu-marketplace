# 업무 문서 작성

독자가 이해·판단·행동하는 데 필요한 내용을 요청한 언어와 형식으로 쓴다. 정보 선별과 문서 배치, 문장·문단 구성, 편집 범위를 맡고 필요한 언어·외부 작업 지침은 같은 초안에 적용한다.

## 절차

1. 문맥에서 독자·목적·출력 언어·편집 범위를 파악하고 결과를 좌우하는 누락 정보만 확인한다. 짧은 답변·한 문장 수정·지정 구간 편집은 해당 범위에서 바로 작성한다. 장문 새 문서는 독자·목적·핵심 메시지 한 문장과 [문서 유형](references/document-types.md)을 먼저 정한다.

   | 요청 | 작성 범위 |
   |---|---|
   | 새 작성 | 제공된 사실·합의로 구성하고 미확인 내용은 그 상태로 둔다. |
   | 부분 수정 | 지정된 문장·항목과 필요한 연결만 고치고 나머지 제목 체계·순서·내용을 유지한다. |
   | 전체 재작성 | 자유 초안의 문장·문단·제시 순서를 바꾸되 지정 양식과 실행 절차의 의미·순서는 유지한다. |
   | 요약 | 목적에 맞게 줄이고 남긴 주장의 조건·예외·확실성을 보존한다. 절차 요약은 개요임을 밝히고 원 절차의 위치를 남긴다. |

2. 영속 문서의 새 작성·갱신·정리라면 갱신 위치를 정한다. 사용자 지정과 프로젝트 관례, 앞선 작업에서 확정한 문서 영향·목적·경로·범위를 이어받고 현재 달라진 부분만 확인한다.
   - 이후에도 찾을 사용법·설정·계약·운영 지식은 문서에, 일회성 작업 과정·검사 결과는 작업 보고에 둔다. 회고·검증 보고 자체를 요청받았다면 그 목적에 맞게 쓴다.
   - 허용된 자료에서 관련 문서와 연결 위치를 먼저 살펴 담당 문서를 갱신한다. 독립된 읽기 목적이 있고 기존 문서에 자리가 없을 때 새 문서를 만든다. 짧은 내용은 한 문서에서 완결한다.
   - 상세 내용은 담당 문서에 두고 다른 문서는 요약·링크로 연결한다. README 갱신은 [README 기준](references/readme.md)으로 별도 판단한다. 자료·권한이 부족하면 확인한 범위의 초안과 남은 확인 사항을 반환하고, 링크와 문서는 확인된 경로·내용으로만 만든다.
3. [의미와 형식 보존](references/integrity.md)으로 수정 범위를 정하고 [문장·문단 구성](references/composition.md)을 적용한다. 사용자·프로젝트의 양식과 관례를 우선하고 README는 [README 지침](references/readme.md), 코드·API 주석은 [주석 지침](references/comments.md), 동료 요청·보고·인계는 [메시지 지침](references/messages.md)을 읽는다.
4. [협업과 언어 선택](../../references/collaboration.md)에 따라 필요한 지침만 보탠다. 독자·목적·선별한 사실·언어·편집 범위·구성을 공유해 한 초안에 반영한다. 티켓·PR은 전달된 항목 안에서 쓰고, 양식이 없으면 주어진 사실로 임시 초안을 만든다. 표현 선호와 사실·조건·고정 양식이 충돌하면 보존 기준을 따른다.
5. 초안을 원문·요구사항과 대조해 사실·조건·확실성·편집 범위·보호 문자열을 확인한다. 영속 문서는 필요한 정보의 누락·상세 설명 중복·불필요한 파일 생성·링크를 확인하고 외부 작업 담당자가 전달한 필드·연결 문법·첨부 위치를 유지한다. 장문에는 [퇴고 점검](../../references/revision.md)을 적용한다.

## 결과

설명이나 비교를 요청받지 않았다면 요청한 글을 반환한다. 자료·권한이 부족한 부분은 확인한 범위와 남은 확인 사항으로 구분한다. 초안과 게시 준비·실제 게시 상태를 구분한다.

## 예시

입력: “장비 대여 안내를 짧게 써 줘. 대여 시간은 평일 10~17시, 학생증이 필요하고 예약 여부는 아직 정하지 않았어. 결과만 줘.”

결과:

> 장비는 평일 10~17시에 학생증을 제시하고 빌릴 수 있습니다. 예약 필요 여부는 아직 정하지 않았습니다.

부분 수정 요청이 “대여 시간만 11~17시로 바꿔 줘”라면 시간만 바꾸고 학생증·예약 안내는 유지한다.

## 경계

- 글 작성 요청만으로 파일 생성·원격 조회·게시·링크에 따른 상태 변경을 수행하지 않는다. 해당 작업의 담당 절차와 사용자 권한을 따른다.
- 언어별 표현은 설치된 Fluent 스킬에, 티켓·PR 양식 조회·필수 항목·게시 절차는 Workflow에 맡긴다. 전달된 초안만으로 저장소·팀 양식이 확인됐다고 판정하지 않는다.

## 참고 자료

- 장문·여러 문서의 작성·편집을 여러 단계로 맡은 주 조정자는 파일 쓰기가 허용된 경우 [작업 연속성](../../references/continuity.md)에 원문·초안·처리 구간을 기록한다. 다른 작업의 문체만 돕는 경우에는 주 작업 기록을 사용한다.
- 함께 적용할 스킬과 호스트별 호출 표기는 [협업과 언어 선택](../../references/collaboration.md)에 둔다.
