# 퇴고 점검

장문의 초안을 반환하기 전에 아래 항목을 차례로 대조한다. 고칠 곳만 고치고 사실·조건·코드·고정 양식은 보존한다.

- **뼈대 통독**: 소제목과 각 문단의 첫 문장만 읽어도 이야기가 이어지는지 본다. 끊기면 문단 순서나 첫 문장을 고친다.
- **소리 내 읽기**: 읽다가 숨이 막히거나 다시 읽게 되는 문장을 찾아 나눈다.
- **덜어낼 말**: 빼도 뜻이 같은 단어와 문장을 지운다.
- **용어**: 용어를 처음 쓸 때 정의하고, 끝까지 같은 용어를 쓰는지 본다. 같은 대상을 여러 이름으로 부르지 않는다.
- **예제**: 예제가 실제 코드나 실제 상황에서 왔는지 본다. 지어낸 예제는 근거로 쓰지 않는다.
- **반복**: 같은 문장 틀이 세 번 이상 이어지지 않는지 본다.
- **근거**: 주장의 강도가 근거보다 세지 않은지 본다. 관찰하지 않은 결과를 단정하지 않는다.
- **혼란 패턴**: 정의 없이 쓴 용어, 추상적인 설명으로 시작하는 문단, "왜" 없이 "무엇"만 늘어놓은 설명이 있는지 본다. 이 세 가지는 [Julia Evans의 혼란스러운 설명 패턴](https://jvns.ca/blog/confusing-explanations/)에서 골랐다.
