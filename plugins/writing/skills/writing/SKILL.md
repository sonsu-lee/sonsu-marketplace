# 업무 문서 작성

독자가 이해·판단·행동하는 데 필요한 내용을 요청한 언어와 형식으로 쓴다. Writing은 문장 관계,
문단 역할, 정보 순서와 편집 범위를 맡는다. 언어별 표현은 Fluent, 티켓·PR 양식과 외부 작업은
Workflow가 맡으며, 각 플러그인은 단독으로 쓰거나 필요한 지침을 함께 적용할 수 있다.

## 요청한 범위에서 작성한다

문맥에서 독자, 목적, 출력 언어와 편집 범위를 파악한다. 결과를 좌우하는 정보가 빠졌을 때만
확인하고, 나머지는 알려진 내용으로 진행한다. 짧은 답변·한 문장 수정은 바로 작성한다.

| 요청 | 다루는 범위 |
| --- | --- |
| 새 작성 | 제공된 사실·합의로 목적에 맞는 구성을 만든다. 미확인 내용은 그 상태로 남긴다. |
| 부분 수정 | 지정된 문장·항목과 필요한 연결만 고치고, 나머지 제목 체계·순서·내용을 유지한다. |
| 전체 재작성 | 자유 초안의 문장·문단·제시 순서를 바꿀 수 있다. 지정 양식과 실행 절차의 의미·순서는 유지한다. |
| 요약 | 목적에 맞게 정보를 줄이고 남긴 주장의 조건·예외·확실성을 보존한다. 절차 요약은 개요임을 밝히고 원 절차의 위치를 남긴다. |

[의미와 형식 보존](references/integrity.md)으로 수정 가능한 범위를 정하고,
[문장·문단 구성](references/composition.md)에 따라 읽기 어려운 관계를 다듬는다.

## 필요한 지침으로 한 초안을 작성한다

사용자·프로젝트가 지정한 양식과 작성 관례를 우선하고, 작성 대상에 맞는 참고 자료를 읽는다.

| 작성 대상 | 참고 자료 |
| --- | --- |
| README | [처음 읽는 사람의 이해와 실행](references/readme.md) |
| 코드·API 주석 | [호출 계약, 이유와 유지보수 정보](references/comments.md) |
| 동료에게 보낼 요청·보고·인계 | [메시지의 요청과 맥락](references/messages.md) |

티켓·PR은 전달받은 항목 안에서 설명을 구성한다. 구체적인 기본 양식·필수 항목·양식 조회와
게시 절차는 `workflow:to-ticket` 또는 `workflow:to-pr`이 맡는다. 양식이 전달되지 않았으면
주어진 사실로 임시 초안을 작성하고, 저장소나 팀의 유효한 양식인지 확인하는 일은 해당 절차에 남긴다.

현재 사용할 수 있는 Fluent 지침 중 **요청된 출력 언어**에 맞는 지침을 함께 적용한다.
프롬프트 언어와 구분하고, 여러 언어는 각 부분에 맞춰 선택한다.

| 출력 언어 | 선택적 표현 지침 |
| --- | --- |
| 한국어 | `fluent-languages:fluent-korean` |
| 일본어 | `fluent-languages:fluent-japanese` |
| 영어 | `fluent-languages:fluent-english` |

이미 적용 중인 지침에 필요한 지침만 보태고, 독자·목적·사실·출력 언어·편집 범위와 정해진 구성을
공유해 같은 초안에 반영한다. 다른 플러그인이 없으면 Writing의 구성·보존 지침으로 작성한다.
표현 선호가 사실·조건·고정 양식과 충돌하면 보존 기준을 따른다.

외국어 인용·고유명·기술 용어는 유지하고, 코드 주석·commit message·UI처럼 프로젝트가 관리하는
문자열은 사용자 지시와 프로젝트 관례를 따른다.

## 의미와 형식을 대조해 반환한다

초안을 원문·요구사항과 대조해 사실·조건·확실성·편집 범위와 보호 문자열을 확인한다.
외부 작업 담당자가 전달한 양식·필수 필드·연결 문법·첨부 위치도 유지한다. 원격 조회·게시와
링크에 따른 상태 변경은 해당 담당 절차와 사용자 권한에 따르며, 초안 작성만으로 게시 준비가
완료되는 것은 아니다. 설명이나 비교를 요청받지 않았다면 요청한 글을 반환한다.

장문·여러 문서의 작성과 편집을 여러 단계로 맡은 주 작업 조정자는 파일 쓰기가 허용된 경우
[작업 연속성](../task-continuity/SKILL.md) 지침으로 원문·초안·처리 구간을 기록한다.
다른 작업의 출력 문체만 담당할 때는 별도 기록을 만들지 않는다.
