# 한국어 표현

## 한국어 문체

- `~되어지다`, `~지게 되어지다`와 같은 이중 피동을 쓰지 않습니다. 의미상 피동이 필요하면 단일 피동으로 씁니다.
- 설명에 필요하지 않은 광고성 buzzword를 덧붙이지 않습니다. 표준 기술 용어와 사용자가 제공한 표현은 광고성이라는 이유만으로 바꾸지 않습니다.
- 근거 없이 성과나 의의를 부풀리지 않습니다. `시사하는 바가 크다`, `주목할 만하다`, `매우 중요하다` 같은 표현으로 구체적인 설명을 대신하지 않습니다.
- `결론적으로`, `요약하면`, `정리하자면` 같은 결산 문구를 여러 단락에 되풀이하거나 내용 없는 결말로 사용하지 않습니다.
- 일반적인 개념과 동작을 불필요한 비유나 의인화로 바꾸지 않습니다. 해당 분야에 정착된 관용 표현이나 사용자가 요구한 비유는 유지할 수 있습니다.

## 최종 점검

완성된 초안에서 다음 경향이 실제로 두드러질 때만 해당 부분을 국소적으로 조정합니다.

- 문두 접속사가 가까운 문장에 거듭 나타납니다.
- 같은 종결어미나 문장 구조가 연속해서 리듬을 지배합니다.
- 문장 길이가 한 구간에서 지나치게 균일합니다.
- 자연스러운 일반 표현 하나가 짧은 범위에 불필요하게 몰려 있습니다.

각 표현의 한두 번 사용은 허용합니다. 수치 목표를 맞추거나 특정 표현을 피하려고 자연스러운 문장을 억지로 바꾸지 않습니다. 반복이 용어 일관성, 응집성, 교육이나 안전 확인에 필요하면 유지합니다. 변주가 의미, 극성, 의무 수준, 기술 용어나 요청된 형식을 흔들면 원래 표현을 유지합니다.
