# 제품 근거 종합

여러 제품 근거를 감사 가능한 형태로 종합하여 후속 탐색과 결정에 사용할 입력을 만든다. theme은
자료에서 관찰한 패턴이며 전체 사용자나 시장의 진실로 확대하지 않는다.

## 경계

- 제공되었거나 허용된 제품 자료의 분류, 비교와 종합을 담당한다.
- 새로운 외부 출처를 폭넓게 찾는 일반 리서치와 경쟁사 조사는 담당하지 않는다.
- 제품 문제, 우선순위, roadmap, 요구사항과 승인 상태를 대신 결정하지 않는다.
- 원문을 임의로 보완하거나 존재하지 않는 발화, 빈도, 심각도와 사용자를 만들지 않는다.
- 비공개 자료를 공개 검색, 외부 모델이나 승인되지 않은 시스템으로 전송하지 않는다.

## 분석 계약을 고정한다

다음 내용을 먼저 확인한다.

- 답할 제품 질문과 분석 범위
- 포함한 출처, 리비전, 수집 시점과 접근 범위
- 분석 단위: 사람, 계정, 세션, 발화, 이슈 또는 사건
- 기존 codebook을 적용하는 연역적 분석인지, 후보 theme을 찾는 귀납적 분석인지
- 빈도, 심각도와 확신도를 판단할 수 있는 자료인지
- 결과를 사용할 다음 결정과 잘못된 결론의 위험

분석 단위나 같은 사람·사건의 중복 여부를 확인할 수 없으면 빈도를 사람 수처럼 표현하지 않는다.
핵심 질문이 모호하지만 안전한 분석이 가능하면 가정을 밝히고 진행한다.

## 근거 원장을 만든다

각 출처에 안정적인 ID를 부여하고 다음 정보를 유지한다.

- 출처 유형, locator, 리비전과 확인 시점
- 관찰 대상과 표본 또는 coverage
- 직접 관찰한 내용과 해석
- 개인정보와 공개 가능 범위
- 중복 가능성, 누락과 수집 편향

짧은 대표 인용은 의미를 바꾸지 않는 범위에서 출처 ID와 연결한다. 민감정보는 필요한 최소
내용만 보존하고 익명화 여부를 밝힌다.

## theme과 반례를 함께 찾는다

자료를 다음 관점에서 비교한다.

- 반복되는 목표, 문제, 행동, 우회 방법과 결과
- 사용자·상황·채널에 따른 차이
- 같은 theme을 지지하지 않는 negative case와 반례
- 출처 사이의 충돌과 서로 다른 설명
- 사용 빈도와 별개인 심각도, 비용과 되돌리기 어려움
- 기존 제품 결정과 일치하는 증거, 새 질문을 만드는 증거

theme마다 포함 기준과 제외 기준을 분명히 한다. 비슷한 표현만으로 합치지 않고, 서로 다른
원인을 같은 기능 요청으로 축약하지 않는다. 새로운 귀납적 theme은 후보로 표시하고 사람이
원문과 분류를 검토할 수 있게 한다.

## 수량과 확신도를 제한한다

- 빈도는 분모, 분석 단위와 중복 제거 방법을 확인할 수 있을 때만 수치로 제시한다.
- 여러 channel에 나타났다는 사실이 독립적인 여러 근거를 뜻하지는 않는다.
- 빈도가 높다는 이유만으로 가치, 우선순위나 인과관계를 확정하지 않는다.
- 작은 표본, 자기선택, recall, moderator와 측정 한계를 기록한다.
- 정확한 수치가 불가능하면 `반복 관찰`, `소수 사례`, `단일 사례`, `미확인`처럼 근거 수준을
  과장하지 않는 표현을 사용한다.

## 결과

다음 순서로 필요한 만큼만 제공한다.

1. 질문, 범위, 출처와 분석 단위
2. 출처 ID와 핵심 관찰을 연결한 근거 원장
3. theme별 지지 근거, 대표 인용, 빈도와 심각도
4. negative case, 충돌과 경쟁 설명
5. 자료와 분석의 한계
6. 제품 탐색에 반영할 수 있는 시사점과 아직 내릴 수 없는 결정
7. 다음 확인 행동과 사람의 검토가 필요한 항목

핵심 theme이 원문 근거로 다시 추적되고, 반례와 불확실성이 숨겨지지 않으며, 관찰과 제품
결정이 구분될 때 완료한다.
