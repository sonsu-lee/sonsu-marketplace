# assess-product-test: 제품 검증 판정

실행된 검증이 원래 질문에 어떤 증거를 제공하는지 판정한다. 기대했던 결과를 정당화하기 위해
사후에 가설, 표본, 지표나 기준을 바꾸지 않는다.

## 경계

- 사전에 정한 test plan과 실제 실행·관찰을 비교한다.
- 원자료가 없는 요약이나 발표 자료만으로 강한 결론을 만들지 않는다.
- 누락된 기준을 사후에 만들어 원래 계획의 성공 기준처럼 사용하지 않는다.
- 제품 roadmap, 출시, 중단, 예산과 우선순위를 대신 승인하지 않는다.
- 실행하지 않은 test를 실패나 성공으로 판정하지 않는다.

## 입력을 고정한다

다음 자료와 리비전을 확인한다.

- 원래 가설, competing explanation과 test plan
- 사전에 정한 primary signal, guardrail과 판정 기준
- 실제 모집, 표본, 절차, 노출, 기간과 instrumentation
- 원자료 또는 다시 확인할 수 있는 결과 위치
- 계획에서 벗어난 실행 편차, 누락과 데이터 제외
- 결과를 사용할 결정과 현재 승인 범위

plan이나 결과가 여러 리비전이면 어떤 조합을 판정하는지 명시한다. 결과를 본 뒤 수정한 분석은
사전 분석과 구분하여 exploratory result로 표시한다.

## 실행 유효성을 먼저 확인한다

결과의 방향보다 다음 내용을 먼저 확인한다.

- test가 실제로 실행되었는가?
- 대상 사용자와 상황이 가설 범위에 맞는가?
- 노출, 비교 조건과 instrumentation이 의도대로 작동했는가?
- 중복, 오염, 중도 이탈과 누락이 결과를 바꾸는가?
- 표본과 기간이 계획한 판단을 뒷받침하는가?
- 개인정보, 동의, 중단 기준과 guardrail 위반이 있는가?

실행이 가설을 검사하지 못했다면 수치가 좋아도 `invalid` 또는 `inconclusive`로 판정한다.

## 사전 기준에 따라 판정한다

다음 상태를 구분한다.

- `not-run`: 계획만 있고 검증이 실제로 실행되지 않았다.
- `invalid`: 실행 또는 측정 결함 때문에 결과를 해당 가설에 사용할 수 없다.
- `inconclusive`: 검증은 실행됐지만 사전 기준을 충족하거나 반증하기에 증거가 부족하거나
  양립 가능한 설명이 남는다.
- `supported`: 정의한 범위에서 관찰이 사전 기준을 충족하고 중요한 competing explanation이
  현재 근거로 충분히 약화됐다.
- `invalidated`: 정의한 범위에서 관찰이 사전 반증 기준을 충족한다.
- `mixed`: primary signal, guardrail, segment 또는 반복 결과가 서로 다른 방향을 보인다.

`supported`는 가설이 영구히 참이라는 뜻이 아니고, `invalidated`는 모든 대안이 실패했다는 뜻이
아니다. effect size, 불확실성, 실제 중요도와 일반화 범위를 함께 설명한다.

## 반례와 민감도를 확인한다

- 제외한 자료와 다른 합리적인 처리에서 판정이 바뀌는지 확인한다.
- segment 차이가 사전 계획인지 사후 탐색인지 구분한다.
- novelty, seasonality, selection, survivorship, observer effect와 외부 사건을 검토한다.
- 결과가 행동, 만족, 매출, 비용 또는 proxy 가운데 무엇을 직접 측정했는지 밝힌다.
- 동일 사용자나 사건이 여러 channel에서 중복 집계되지 않았는지 확인한다.

추가 분석이 새 데이터 수집, 외부 접근 또는 제품 변경을 요구하면 판정과 분리하여 필요한
승인을 알린다.

## 결과

다음 순서로 보고한다.

1. plan과 실행 리비전, 가설과 대상 범위
2. 실제 실행 여부와 주요 편차
3. 사전 기준별 관찰 결과
4. 판정과 확신을 제한하는 근거
5. competing explanation, 반례와 guardrail
6. 현재 증거가 허용하는 결정과 허용하지 않는 결정
7. continue, revise, pivot, stop 또는 재검증 후보와 별도 승인 사항

판정이 원자료와 사전 기준으로 추적되고, 실행 결함과 불확실성이 숨겨지지 않으며, 제품 결정과
증거 판정이 구분될 때 완료한다.
