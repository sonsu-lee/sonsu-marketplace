# 빠른 점검 규칙

초안을 점검할 때 사용하는 규칙이다. 애매하면 [전체 패턴](ai-tell-taxonomy.md)과 [교정 방법](rewriting-playbook.md)의 해당 항목을 확인한다. 각 규칙의 조건·예외를 함께 적용한다.

- 사실·조건·서법·시제·부정·인과와 기존 문체를 먼저 보존한다. 입력에 없는 내용은 추가하지 않는다.
- 고유명사·수치·날짜·단위·직접 인용·법조문·코드·명령·식별자·로그·링크 대상·사용자 지정 문자열은 보호한다. 그대로 유지하도록 지정된 인용문·승인 문구는 바깥따옴표와 구분자까지 보존한다.
- 개념어와 기술용어는 반복 회피만을 위해 삭제하거나 동의어로 돌리지 않는다. 사용자 요청에 따른 번역·현지화는 값과 의미를 유지한다.
- 횟수·길이는 점검 단서이며 강제 할당량이 아니다. 실제로 읽기를 방해하지 않으면 유지한다. 표현의 출현으로 AI 작성 여부를 판단하지 않는다.
- 기술 문서의 목록·표·절차·고정 제목을 보존한다. 빈도·분포 규칙을 초안 작성 전 금지 규칙으로 사용하지 않는다.

## A. 번역투 (Translation-ese) — S1~S2

- **A-1** [S1] "~에 대해(서)" **한 문단 3회+ 밀집**(사람이 3배 더 쓰는 표현 — 기본 보존) → 목적격 조사로 직결("X에 대해 논의" → "X를 논의")
- **A-2** [S2] "~를 통해/통하여" **문단 3회+ 반복** → 일부만 "~로", "~해서", "~함으로써"로 분산(1~2회 보존)
- **A-3** [S1] "~에 있어(서)" → "~에서" 또는 "~을 볼 때"
- **A-4** [S2] "~라는 점에서" 3회+ → "~서", "~라는 이유로"
- **A-5** [S2] “~와 관련하여/관련된” → 관계와 범위가 같을 때만 간결하게 정리. “사용자와 관련된 데이터”를 “사용자의 데이터”로 바꾸지 않음
- **A-6** [S2] "~에 기반하여/바탕으로" 남발 → "~로", "~을 보고"
- **A-7** [S1] "가지고 있다", have/make/take/give+명사 직역 → 형용사-동사 환원 또는 이중주어("강한 경쟁력을 가지고 있다" → "경쟁력이 강하다")
- **A-8** [S1] 이중 피동 “판단되어진다” → “판단된다”. 상태 변화의 “~지게 된다”와 필요한 피동·진행은 유지
- **A-9** [S2] “~에 의해” 피동 → 행위자가 확인되고 의미·정보 초점·문체를 유지하며 더 자연스러울 때만 능동형으로 전환. 결과·상태가 중심이거나 행위자가 부차적이면 피동 유지(“접근은 정책에 의해 제한된다”)
- **A-10** [S2] “~할 수 있다” 반복 → 가능성·능력·허용의 뜻을 보존하며 연결·배치만 조정. 기능 목록의 반복은 유지
- **A-11** [S2] "~을 위해" 목적절 남발 → "~려고", "~도록", "~위한"
- **A-15** 추상 주어 + 만능 동사 → 원문에서 확인한 행위자·관계만 구체화. suggest를 증명·확정으로 바꾸지 않음
- **A-16** 지시 대상이 불명확하거나 불필요한 대명사 반복 → 문맥 전체에서 대상과 강조·대조 의도를 확인. 명확하면 생략 가능, 모호하면 원문 유지. 후보 개수·삭제 비율 강제 없음
- **A-18** 길거나 중첩된 수식이 이해를 방해함 → 조건·수식 대상·시간 순서를 보존하며 분리. 어절 수만으로 고치지 않음
- **A-19** 이중 조사 "~에서의/~에로의/~으로의/~에의/~으로부터의" → 절-구로 풀어쓰기, 단순 "~의"는 비대상
- **A-20** [S2] “~되고 있다/~지고 있다” 밀집 → 진행 상태를 유지해 필요한 부분만 정리(“심화되고 있다” → “심해지는 중이다”). 완료형으로 바꾸지 않음
- **A-21** [S2] "단순한 X를 넘어 Y" 범위 상승이 실제 내용을 흐림 → "X만이 아니라 Y다"로 풀거나 넘어-구 삭제
- **A-22** “~은/는 명확하다·분명하다” → 확신과 명제를 보존하며 불필요한 강조만 정리. 구체 근거가 없으면 사실·수치 추가 금지
- **A-24** "더 이상 ~ 않다/아니다" 문서 2회+ 또는 결말부 재정의 문장 → "더 이상"을 "이제"로 환원하거나 변화 동사로 편다. 부정 명제를 긍정 단언으로 올리지 마라. **윤문 중 "더 이상 A가 아니라 B"를 새로 만들지 마라**

## B. 영어 인용·용어 과다 — S2

- **B-1** [S2] 반복되는 영어 병기 → 첫 설명 후 문서에서 정한 표기로 통일. 일반 윤문에서는 표준 약어·공식 명칭을 보존하고, 명시적인 번역·풀어쓰기 요청은 지정 범위에서 반영
- **B-2** [S2] 설명 없이 낀 광고성 buzzword(seamless·robust·leverage 등) → 광고성은 한국어로 풀고, 일반 윤문에서는 표준 technical term(API·prompt·token 등)을 보존. 명시적인 번역·풀어쓰기 요청은 설명문의 지정 범위에서 의미를 유지해 반영하며 코드·식별자 등으로 확대하지 않음. 기계적 직역 금지

## C. 구조적 AI 패턴 (서식·레이아웃) — S1~S2

- **C-2** [S2] 에세이·칼럼·비기술 산문형 리포트의 장식성 불릿 → 항목 구분이 불필요할 때만 산문으로 잇는다. 기술 문서·runbook·명령 목록·절차·요구사항·비교 항목과 요청한 형식은 유지
- **C-5** [S1] 이모지 장식 반복 → 읽기를 방해하는 장식만 줄임. 상태·경고·범례·요청한 서식은 유지
- **C-7** 문단 문두 "먼저-반면-결국" 3단 공식 → 순서·대조·인과를 유지하며 중복 연결어만 정리
- **C-8** 같은 대구가 연쇄되어 읽기를 방해함 → 실제 부정·대안·대조를 보존하며 필요한 부분만 재배치. 개수 할당과 새로운 대구 삽입 금지
- **C-9** 숫자 괄호 인덱싱 → 절차·요구사항·비교·참조 번호는 유지. 의미 없는 산문 분절만 정리
- **C-10** 콜론 부제 헤딩 "X: Y" 반복 → 헤딩을 단일 명사구로 압축, 단 학술-보고서의 실제 절 제목은 보존
- **C-11** 연결어미 뒤 쉼표 반복 → 불필요한 쉼표만 제거. 긴 절 경계·오독 방지·의도한 호흡은 유지

## D. AI 특유의 관용구 (Signature Phrases) — S1

- **D-1** 결산 표현 “결론적으로/따라서/이를 통해/그러므로/요약하면/정리하자면” 반복 → 중복만 정리하고 인과·요약 기능은 보존
- **D-2** "시사하는 바가 크다/주목할 만하다/매우 중요하다" 류 의의 과장 → 중복 강조만 정리하고 실제 중요성·평가는 보존
- **D-3** 열거 도입 "크게 세 가지로 나눌 수 있다/다음과 같은" → 뒤의 내용과 중복되는 도입만 삭제하고 분류·범위 정보는 보존
- **D-4** 과장 어휘 반복 → 입력에 있는 수치·사실로만 구체화. 근거가 없으면 과장 수식만 줄이고 주장 보존
- **D-5** 의인화 추상 주어 → 확인된 행위자만 쓰거나 동사를 평이하게 바꿈. 주체를 만들어 넣지 않음
- **D-6** 결말 공식 “~할 때입니다/~시점입니다” 반복 → 권고·시점 의미를 유지하며 중복만 정리
- **D-7** “X에서 Y로/X을 넘어 Y로” 반복 → 변화의 방향·범위·전망을 보존하며 불필요한 슬로건만 정리
- **D-8** 분열문 "필요한/중요한 것은 ~이다" + 명사 변종 "문제는/핵심은/관건은/답은 ~다·~는 점이다·~데 있다" → 주어-서술 직결로("필요한 것은 방향이다" → "방향이 필요하다" / "논쟁의 핵심은 생산성이다" → "논쟁은 생산성을 둘러싼 것이다")
- **D-9** “~로 이어진다/~에 직결된다/결국” 반복 → 원문에 있는 인과관계만 명확히 씀. 경로 날조나 상투구 추가 금지
- **D-10** [S2] “~하는 이유다” 결산 반복 → 인과·유보를 보존하며 필요하면 순방향 서술로. 횟수 제한 없음
- **D-11** [S2] “향후/앞으로/중장기적으로”의 형식적 반복 → 이미 있는 시점·조건으로 명확히 함. 미래 전망을 나타내면 유지
- **D-12** [S2] 독립 문장 "과제도 남아 있다/한계도 분명하다/아쉬운 점도 있다" → 문패 삭제, 실제 과제를 첫 문장으로
- **D-13** [S2] 에세이 성찰 부사 → 잠정성·속도·완료 시점·개인 문체를 보존하고 중복 장식만 정리
- **D-14** 겹친 은유가 주장을 흐림 → 의미가 확정될 때만 평이하게 풀기. 관용 표현·중심 은유·요청한 비유 유지, 횟수 할당 없음

## E. 리듬·문장 길이 균일성 — S2

- **E-1** 문장 길이의 단조로움 → 의미 연결에 따라 잇거나 나눔. 단문·장문의 개수나 길이를 맞추지 않음
- **E-2** 동일 종결 반복 → 시제·서법·격식을 보존하며 연결·배치만 조정. 진행형과 자연스러운 한다체·합니다체 유지
- **E-7** 의도하지 않은 격식 혼재 → 같은 화자의 문체를 일관되게 유지. 다른 화자·직접 인용·관계에 따른 말투는 보존

## F. 과도한 수식·중복 — S2

- **F-2** “중요하고 핵심적인”처럼 같은 뜻을 중복한 수식 → 의미·강도를 유지하며 하나로 정리. 서로 다른 특성을 나타내면 유지

- **F-4** 한자어·영어 명사화 누적으로 관계가 흐림 → 동사·형용사로 풀되 정의어·전문용어와 의미 보존
- **F-5** “~적 N” 추상 체인이 관계를 흐림 → 자연스럽게 풀어쓰기(“실천적 기반” → “실천의 기반”). 용어와 정확한 의미가 유지될 때만 적용
- **F-7** 범용 정책동사·추상 목적어 → 입력에 확인된 행위만 구체화. 수단·주체·의무를 추가하지 않음

## G. 과도한 Hedging (완곡) — S2

- **G-1** 같은 추측 종결 반복 → 유보·판단 주체·극성을 유지하며 배치 조정. 단정 전환 금지
- **G-2** 이중·삼중 완곡 → 같은 극성·확신도가 확실할 때만 중복 정리. 부정 중첩·협상·계약 문서는 유지
- **G-3** **보류**: “양쪽 모두/장점도 있지만/신중하게/균형”의 빈도로 교정하지 않음. 한쪽 단언으로 바꾸지 않음

## H. 접속사 남발 — S2

- **H-1** 접속사 밀집 → 논리 연결을 보존하며 실제 중복만 정리. 삭제 비율 없음
- **H-3** 메타 진입 "이는 ~/이 점에서/이 관점에서/이 말은"이 **한 문단 3회+** 반복 → 그중 일부만 본 서술로 직진(문서 단위 일괄 삭제 금지 — 사람도 쓰는 패턴)
- **H-4** “즉” 반복 → 필요한 정의·동격·풀이 기능은 보존하고 중복만 정리. 횟수 제한 없음

## I. 형식명사·의존명사 과다 — S2

- **I-1** “~한 것이다/~일 것이다” 연속 반복 → 설명 기능·추측·예정을 보존하며 필요한 부분만 정리. 단정 전환 금지
- **I-2** "주목할 점은/X은 ~라는 점에 있다" 형식명사 강조 → "X는 ~다" 직설로
- **I-3** “~다는 것이다/~다는 뜻이다” 반복 → 풀이·인용·유보를 유지하며 중복만 정리. 횟수 제한 없음
- **I-4** 당위로 끝나는 문단 반복 → 순서·조건·범위가 같을 때만 문장 이동. 의무를 사실·추측으로 치환하지 않음
- **I-7** 출처 없는 “~다는 분석이다/평가다” → 평가를 사실로 바꾸거나 출처를 만들지 않음. 유보 유지, 검토 요청 시 확인 사항 표시

## J. 시각 장식 남용 — S2~S3

- **J-1** 문장마다 볼드 강조 → 불필요한 장식만 줄이고 경고·핵심 값·요청한 강조는 유지

- **J-2** 따옴표 강조 5회+ → 진짜 인용만 남기고 평어로
- **J-3** 대시 부가 설명의 과도한 반복 → 관계를 명확히 풀되 필자의 의도한 문체는 유지. 사용 횟수 제한 없음

## 자체검증 체크리스트

1. **사실과 의미**: 주체·행동·조건·인과·부정·가능성·의무·진행 상태가 유지되는가.
2. **보호 대상**: 수치·날짜·용어·직접 인용·코드·명령·링크·고정 양식이 보존되는가.
3. **편집 범위**: 요청한 구간만 고쳤으며 이미 자연스러운 문장을 불필요하게 바꾸지 않았는가.
4. **장르와 문체**: 사용자 요구, 화자의 목소리와 기존 격식을 유지했는가.
5. **적용 조건**: 해당 패턴의 조건·예외를 확인했는가. 보류·관찰 항목이나 출현 횟수만으로 교정하지 않았는가.
6. **추가 내용**: 원문에 없던 수치·출처·경험·비유·인과관계·약속을 넣지 않았는가.

위반한 수정은 되돌리고 해당 부분만 한 번 다시 점검한다. 불확실하면 원문을 유지한다. 요청한 결과만 반환하고 등급·변경률·별도 파일 저장을 강제하지 않는다.
