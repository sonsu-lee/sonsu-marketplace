# 한국어 윤문 처방집 (Rewriting Playbook)

문제가 확인된 구간을 실제로 고칠 때 따르는 전환 규칙집. [ai-tell-taxonomy.md](ai-tell-taxonomy.md)의 각 패턴별 처방을 **실행 가능한 치환 레시피**로 확장한다.

## 0. 대원칙 (The Prime Directives)

1. **의미 불변(Fidelity)**: 사실·주장·인과·조건·시제·서법의 의미를 보존한다. 수치·고유명사·직접 인용·코드·식별자·명령·로그·링크 대상은 그대로 둔다. 모호해도 임의 보강 금지.
2. **톤 유지(Tone Match)**: 입력이 격식체면 격식체로, 에세이면 에세이로. 윤문이 원래 글을 "다른 장르"로 바꾸지 않는다.
3. **국소성(Locality)**: 문장을 한꺼번에 전부 재작성하지 않는다. AI 티가 있는 구간만 수술적으로 고친다.
4. **자연성 우선, 완벽성 차순(Natural > Perfect)**: 과하게 문학적으로 고치지 않는다. 일상 한국어 필자의 중간값 리듬을 목표.
5. **근거 기반(Span-Grounded)**: 모든 문체 교정은 확인한 문제 구간과 연결된다. 별도 탐지 리포트는 요구하지 않는다.
6. **과윤문 경고(Over-Polish Alarm)**: 수정량과 관계없이 의미·문체·형식을 손상시키는 수정은 되돌린다.
7. **빼기 전용(Removal-Only)**: 치환은 AI 티를 빼는 방향이다. 처방 예시의 어휘를 원문에 없던 자리에 새로 심지 않는다. 원문보다 격식을 올리지 않는다 — '-했-' → '-하였-' 금지, '~인데요/~거든요/~한 겁니다' 구어 종결 보존. 필자의 의도한 구어는 보존한다.

## 1. 카테고리별 치환 레시피

> 아래 예시는 한다체로 표기했으나, 출력의 격식(합쇼체·해요체·한다체)은 언제나 원문을 따른다. 예시의 격식을 베끼지 말 것. 각 예시는 해당 패턴의 적용 조건을 만족할 때만 사용한다. 원문에서 주체·범위·강도·시제가 확인되지 않으면 예시대로 치환하지 않는다.

### A. 번역투 레시피

| 원문 패턴 | 윤문 예시 |
|-----------|----------|
| X에 대해 논의한다 | X를 논의한다 / X를 이야기한다 |
| X를 통해 Y한다 | X로 Y한다 / X해서 Y한다 / X함으로써 Y한다 |
| X에 있어서 | X에서 / X를 볼 때 / X에서는 |
| X라는 점에서 | X해서 / X라는 이유로 / X이기 때문에 |
| X와 관련하여 | X에서 / X에는 / X를 두고 |
| X에 기반하여 / X을 바탕으로 | X로 / X를 근거로 / X를 보고 |
| 경쟁력을 가지고 있다 | 경쟁력이 있다 / 경쟁력이 강하다 |
| 판단되어진다 | 판단된다. 행위자가 명시되어 있고 초점이 유지될 때만 능동형 허용 |
| AI에 의해 생성된 | AI가 만든 |
| 높일 수 있다 | 높일 수 있다 (가능·능력·허용의 뜻을 보존). 반복이 문제면 배치만 조정 |
| X을 위해 Y한다 | X하려고 Y한다 / X하도록 Y한다 |
| 합의가 이루어졌다 | 합의가 이뤄졌다. 참여자가 입력에 명시되고 초점이 유지될 때만 “양측이 합의했다”처럼 능동형 허용 |
| 기술 발전 속도 가속화 | 기술의 발전 속도가 빨라진다 |
| 그리고 (문두) | (삭제) / "-고" 연결어미로 압축 |

### B. 영어 인용·용어 처방

- **괄호 병기**: 일반 독자 대상 → 첫 등장 1회만 영어 병기, 이후 한국어만. 전문 독자 대상 → 영어 병기 유지하되 매번 반복하지 않음.
- **영어 단어 번역표 (빈출)**:
  - pipeline → 파이프라인 (유지 OK) / 흐름 / 공정
  - framework → 체계 / 틀 / 구조
  - leverage → 활용하다 / 기대다 / 끌어올리다
  - seamless → 매끄러운 / 끊김 없는
  - robust → 튼튼한 / 견고한
  - scalable → 확장성 있는
  - insight → 통찰 / 눈 / 시사점
  - impact → 영향 / 파장
  - holistic → 전체적 / 총체적
- **영어 인용구**: 원문 어감이 핵심이면 유지하고 한국어 번역 병기. 직접 인용을 임의 번역하거나 삭제하지 않는다. 번역·요약을 요청받았을 때만 인용과 번역을 구분한다.

### C. 구조 레시피

- **대칭 대구 해체 (C-8)**. 반복이 읽기를 방해할 때만 **한쪽을 길게 풀고 다른 쪽은 짧게 끊거나,
  한 문장을 둘로 나누거나, 두 주장 사이의 관계를 유지하며 연결하는 것**이다:
  - "기술은 도구이고, 사람은 주체다. 데이터는 연료이며, 알고리즘은 엔진이다."
    → 의도한 역할 비유이므로 유지한다. “데이터가 있어야 알고리즘이 돌아간다”처럼 새로운 필요조건으로 풀어 쓰지 않는다.
  - "중요한 것은 속도가 아니라 방향이며, 양이 아니라 질이다."
    → "속도보다 방향이 중요하고, 양보다 질이 중요하다."
  - "기계는 답을 주지만, 질문은 주지 않는다."
    → "기계는 답을 준다. 질문을 주지는 않는다."
  실제 대조·부정·필자의 의도한 수사는 유지한다. 남길 개수를 강제하지 않는다.

- **기계적 병렬 "첫째/둘째/셋째"**:
  - 열거가 핵심이면 → 항목·번호·순서·병렬 구조 유지.
  - 열거가 장식이면 → 산문으로 녹이기: "A다. B도 마찬가지다. 여기에 C가 더해진다."
- **불릿 → 산문 전환 예시**:
  - 원문:
    ```
    - 속도가 빠르다
    - 비용이 저렴하다
    - 확장성이 높다
    ```
  - 윤문: "속도는 빠르고 비용도 낮다. 확장성도 높다."
- **헤딩 제거**: 에세이·칼럼의 불필요한 도식적 헤딩만 정리한다. 기술 문서·보고서의 절 제목과 요청한 구조는 유지한다.
- **문단 첫 문장 요약 공식 해체**: 내용 없는 요약만 정리한다. 요점 우선 설명과 입력에 없는 장면·수치·질문을 만드는 변경은 하지 않는다.
- **이모지**: 불필요한 장식만 줄인다. 상태·경고·범례·요청한 서식은 유지한다.

### D. 관용구 처방 (삭제 우선)

- **분열문·결산 공식 해체 (D-8·D-9·D-10 — 예시로 시연)**. 의미와 강도가 보존되는 범위에서 적용한다:
  - "주 4일제 논쟁의 핵심은 생산성 전환이다." → "주 4일제 논쟁은 생산성을 어떻게 바꾸느냐로 모인다."
  - "문제는 양측이 합의에 이르는 경우가 거의 없다는 점이다." → "양측이 합의에 이르는 경우가 거의 없다는 점이 문제다."
  - "그 부담은 결국 소비자 가격으로 전가된다. … 결국 세금으로 돌아온다." → 뒤의 "결국"만 남기거나 둘 다 삭제: "그 부담은 소비자 가격으로 전가된다. … 세금으로 돌아온다."
  - "일률적인 도입이 현실적이지 않은 이유다." → "그래서 일률적인 도입은 현실적이지 않다."
  ⚠️ 결말을 다듬으며 "~하는 이유다"·"~해야 한다"를 **새로 만들지 않는다**(D-10·I-5 주입 금지).

| 삭제 대상 | 대안 |
|----------|------|
| 결론적으로 | (삭제) — 마지막 문단 자체가 결론이므로 라벨링 불필요 |
| 요약하면 / 정리하자면 | (삭제) 또는 "한 줄로 말하면" |
| ~라고 할 수 있다 | 유보·관측의 의미를 유지하며 중복된 표현만 정리한다. 다른 문장의 단정을 근거로 현재 문장의 유보를 삭제하지 않는다 |
| 매우 중요하다 | 원문에 확인된 근거가 있을 때만 구체화한다. 중요성을 필수 조건으로 바꾸지 않는다 |
| 시사하는 바가 크다 | 겹친 강조만 덜어내며 구체적인 시사점이 있으면 유지 |
| 주목할 만하다 | 같은 평가가 겹친 장식일 때만 중복을 줄인다. “이 결과는 주목할 만하다”처럼 독립된 평가나 중요성 판단은 보존 |
| 혁신적인 / 획기적인 | 과장 수식만 덜어낸다. 최초·차이의 근거가 입력에 있을 때만 구체화 |
| ~의 지평을 열다 / ~시대가 도래했다 | 삭제 후 실제 변화를 서술 |

### E. 리듬 처방

- 문장 사이의 실제 관계에 따라 잇거나 나눈다. 짧고 긴 문장의 수·비율을 맞추지 않는다.
- 시제·서법·격식은 보존한다. 진행형을 완료형으로 바꾸거나 종결어미 변주를 위해 추측·의무를 추가하지 않는다.
- 기술 문서의 간결한 문장과 한다체·합니다체가 자연스러우면 유지한다.

### F. 수식 처방

- 정도부사("매우", "정말", "대단히") → 중복 장식만 삭제. 강조가 필요하면 입력에 있는 수치·비교만 사용하며 화자의 목소리는 유지.
- 동의어 이중 수식("중요하고 핵심적인") → 문맥에서 같은 의미가 중복될 때만 하나로 줄인다. 서로 다른 특성·강도·기능은 유지하며 “새롭고 혁신적인”도 각 특성을 말하면 모두 남긴다.
- "~적 / ~성 / ~화" 접사 → 구체 동사·명사로 풀기.
  - "근본적 변화" → "뿌리부터 바뀐다"
  - "구조적 문제" → "구조가 문제다" / "구조 자체가 문제다"

### G. Hedging 처방

- 유보·판단 주체·확신도를 유지한다. “~로 보인다” → “~이다”는 단정 전환이므로 금지한다.
- “~할 수 있을 것으로 보인다”의 가능성을 지우고 “~로 보인다”로 줄이지 않는다. 같은 표현이 반복되면 배치를 조정한다.
- 이중·삼중 완곡은 같은 극성·확신도가 확실할 때만 중복을 정리한다. 협상·계약 문서와 부정이 낀 완곡은 유지한다.

### H. 접속사 처방

- 문두 접속사가 밀집하면 → 논리 연결이 중복되는 부분만 정리.
- "또한" → 연결 의미가 중복될 때만 삭제. 연결이 필요하면 유지.
- "따라서 / 그러므로" → 인과가 자명하면 삭제. 필요하면 "그래서"로 교체.
- "하지만 / 그러나" 반복 → 대조 범위를 보존하며 중복만 정리. 단순 변주를 위해 “그런데”로 바꾸지 않음.

### I. 형식명사 처방

- "것이다" 종결 → 설명·추측·예정 기능을 유지하면서 중복만 정리.
  - “이번 결과가 의미하는 것은 변화가 크다는 것이다”는 유지한다. 문장 성분과 설명 기능을 확인하지 않고 “크다는 것이다”를 “크다”로 치환하지 않는다.
- “~할 필요가 있다”의 권고를 “~한다”는 사실이나 더 강한 의무로 바꾸지 않는다. 당위 문장 이동은 조건·순서가 같을 때만 적용한다.
- “~이 필요하다”는 주체·행동이 입력에서 확인되는 경우에만 구체화한다. “혁신이 필요하다”에 제품 재개발 같은 새 행동을 추가하지 않는다.

### J. 장식 처방

- **볼드**: 불필요한 장식만 줄이고 경고·핵심 값·요청한 강조는 유지.
- **따옴표**: 인용·특수 용례에만 한정.
- **대시(—)**: 불필요한 반복만 쉼표·괄호·문장 분리로 정리. 의도한 문체는 유지.

| PE12 | "~로부터·~에 관하여·~을 통하여" | 문맥 자연 표현으로 대체 (전치사구 1대1 매핑 거부) | A-2·A-5 |
| PE13 | 영어 단순 현재·과거 단조 매핑 | 사건의 시점·진행·화자의 경험·확신도를 보존 | E-2 |
| PE14 | 대화체 화자–청자 관계 누락 | 해라/하게/하오/해요/합쇼체 일관 적용 (장르 가드: 대화·구어 한정) | E-7 (estimated, C1) |
| PE15 | "Mr./Ms./Dr." 직역 ("그/그녀") | 입력에서 확인한 호칭만 사용하거나 자연스러울 때 생략 | A-16 |

> **caveat 가드**:
> - C3 — post-editese 3축은 한국어 정량 검증이 없으므로 관찰 관점으로만 사용한다.
> - C5 — PE8/A-19에서 단순 "~의"는 탐지·윤문 대상 명시적 제외.
> - C1 — PE14 청자 경어법 임계는 김혜영 2019 PDF 원문 확보 전까지 "estimated" 유지.
> - PE5(A-17 hold) — 문헌 근거를 유지하되 자동 교정에 사용하지 않는다.

## 2. 수정 결과 확인

교정량을 목표나 중단 기준으로 삼지 않는다. [빠른 규칙의 자체검증](quick-rules.md#자체검증-체크리스트)에 따라 의미·보호 대상·범위·문체·적용 조건·추가 내용을 대조한다. 이미 자연스러운 글은 수정 없이 반환할 수 있다.

## 3. 어휘 대체 위험 (Do-NOT list)

이들은 문체상 AI 티로 보여도 **건드리면 의미가 바뀌는 표현**이므로 보존한다:

- 전문 고유명사·제품명·모델명(GPT-4, Claude 3, Gemini 등)
- 수치·단위·날짜
- 직접 인용된 문장(큰따옴표 "" 내부)
- 법률·규정 조문 인용
- 학술 개념어가 불가피한 경우 (예: "확률적 앵무새", "창발")
- **서법**: 원문이 당위·요구로 말한 것("~해야 한다")을 사실 단정("~한다")으로, 추측·유보로 말한 것("~일 수 있다")을 단정으로 바꾸지 않는다. 주장의 강도와 성격은 보존 대상이다 — 필자가 요구한 것을 이미 일어난 일로 만드는 것은 문체 교정이 아니라 의미 변경이다.
  - 단, **서법의 '보존'과 그 표지의 '반복'은 다른 문제다.** 같은 서법 표지가 반복돼 리듬을 지배하면 서법을 유지한 채 배치를 바꾼다(I-4: 당위 문장을 문단 결말에서 앞으로 이동). 표지를 지우거나 다른 서법으로 바꾸는 것만 금지다.

## 4. 장르별 미세 조정

| 장르 | 허용 | 금기 |
|------|------|------|
| 칼럼·에세이 | 단문, 개인 어조, 문학적 비유 | 이모지, 과한 헤딩, 불릿 남발 |
| 리포트·기술 문서 | 필요한 제목 계층·목록·표·절차·통계·인용·전문용어 | 의미 없는 장식·과장, 코드·수치·고정 양식 손상 |
| 블로그 포스트 | 친근한 어조, 질문형 | 기계적 "첫째/둘째" 공식 |
| 공적 연설·축사 | 격식체, 문어체 | 구어체·이모지·불릿 |

사용자가 지정한 장르·형식·어조를 우선하고 문서 전체의 목적을 확인한다. 표의 문체 선호를 사용자의 요청이나 보호 기준보다 앞세우지 않는다.

## 5. 자체 점검

위반한 수정은 되돌리고 해당 부분만 최대 한 번 다시 점검한다. 불확실하면 원문을 유지한다. 별도 리뷰어·반복 파이프라인·진단 파일을 요구하지 않는다.
