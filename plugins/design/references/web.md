# 웹 환경

브라우저에서 읽고 탐색하고 입력하는 과업을 기존 stack과 컴포넌트로 구현한다. 작은 화면은
데스크톱을 비례 축소하지 않고 필요한 정보·행동에 따라 reflow·단계적 노출·가로 스크롤을 선택한다.

- 링크·버튼·폼 의미, URL 직접 진입과 새로 고침·뒤로/앞으로 가기의 상태를 확인한다.
- 키보드 순서·visible focus·접근 가능한 이름·오류 안내·스크롤과 focus 복귀를 실제로 확인한다.
- 표·편집기 overflow에서는 행/열 맥락과 상세·주요 행동 접근을 유지한다.
- 긴 콘텐츠·현지화·글자 확대·좁은/넓은 창에서 잘림·겹침과 숨겨진 필수 행동을 검사한다.
- 네트워크 대기·오류·중복 제출·취소와 권한 변경은 해당 흐름에 맞춰 다룬다.

검사는 기존 프로젝트의 build/type/lint/test와 실제 브라우저 렌더링·대표 조작을 연결한다.
스크린샷은 시각 증거이며 URL 이동·폼 제출·접근성 동작의 실행 증거를 대신하지 않는다.
