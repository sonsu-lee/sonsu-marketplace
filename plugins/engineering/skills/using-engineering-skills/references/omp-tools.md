# Oh My Pi 기본 하네스 대응

현재 세션에 노출된 도구 스키마와 상위 지침을 우선하고 [실행 계약](agent-execution.md)을 적용한다.
플러그인은 작업 계약과 품질 전이를 소유하며 OMP의 실행·세션·권한 도구를 다시 구현하지 않는다.

- 독립 읽기·리뷰는 새 문맥의 `task` 작업자로 실행한다. 독립 slice는 한 번의 batch로 병렬 실행하고,
  공유 인터페이스와 결과 형식은 `context`에 고정한다. 같은 파일을 동시에 수정하지 않는다.
- 작업자 간 조정은 `hub`의 실제 roster와 메시지를 사용한다. 존재하지 않는 worker나 종료·대기 API를
  추측하지 않는다. 기다리는 동안 직접 수행할 독립 작업이 있으면 계속한다.
- 여러 단계의 진행 상태는 `todo`에 기록한다. evidence gate를 사용한 작업은 스크립트의 실제 결과를
  근거로 완료하며 Codex `Stop` hook이 OMP에서 실행된다고 가정하지 않는다.
- 코드 탐색·수정·검증은 OMP가 제공하는 전용 도구를 우선한다. 심볼 작업은 `lsp`, 구조 검색은
  `glob`·`grep`, UI 확인은 실제 `browser` surface를 사용한다.
- 모델 이름과 reasoning profile은 Codex 문자열을 복사하지 않는다. OMP의 현재 role과 사용 가능한
  모델을 확인하고, 사용할 수 없는 지정은 조용히 대체하지 않고 `blocked` 또는 `not_run`으로 기록한다.
