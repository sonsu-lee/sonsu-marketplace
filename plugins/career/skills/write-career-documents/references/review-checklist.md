# 지원 서류 검토 체크리스트

검토자는 아래 항목을 순서대로 확인한다. 검토자는 서류를 직접 고쳐 쓰지 않는다. 기준은
[근거 규칙](../../../references/evidence-rules.md)과 해당 시장 기준
([미국식 resume](us-resume.md), [履歴書](jp-rirekisho.md),
[職務経歴書](jp-shokumu-keirekisho.md), [スキルシート](jp-skill-sheet.md))이다.

1. 사실 추적: 모든 수치·날짜·직함·규모가 사용 가능한 F-로 이어지는지, 주석 ID의 값과 본문
   값이 같은지 확인한다.
2. private 사실, 철회한 주장(R-), 말하지 않을 것이 없고 anonymize가 적용됐는지 확인한다.
3. 소유권: 팀 성과를 개인 성과로 쓰지 않았고 동사가 `내 몫`과 맞는지 확인한다.
4. bullet·프로젝트별 PSR(✓/△/✗)을 매긴다. 빈칸은 "면접 위험"으로 보고한다.
5. 기술 면접관 관점: 기술 선택이나 해결 서술에 판단 이유가 있는지 확인한다. 이유 없이 "X를
   도입"만 있는 bullet은 지적한다.
6. HR 관점: Matched 요구사항의 JD 표기와 연수가 HR이 훑는 자리에 있는지 확인한다. HR 스크리닝
   시뮬레이션과 별도로 작성자 쪽에서 먼저 점검한다.
7. 해당 시장 기준의 형식 규칙을 확인한다.
8. 금지 표현을 확인한다.
9. 남은 `[VERIFY:]`를 나열한다.
10. (맞춤 모드) Missing을 Matched처럼 표현하지 않았는지 확인한다.

## 출력

`passed` 또는 지적 목록을 낸다. 지적마다 다음을 적는다.

- 위치
- 문제
- 근거(F-/R-/체크리스트 번호/기준 항목)
- 수정 방향
