# Grill me

Invoke `grilling` for a file-free interview: `$development:grilling` in Codex,
`/development:grilling` in Claude Code, or `skill://grilling` in omp. If nested
invocation is unavailable, read the installed skill's `SKILL.md` and identify
that as reading, not invocation; report an inaccessible dependency. Research
available facts and ask only consequential unresolved questions; do not ask
the user to repeat information already provided.
For a writing draft, prioritize unresolved audience, purpose, and central claim.
Do not ask about tone, length, metrics, or examples unless they materially change
the result; choose reasonable defaults where the reader can evaluate them.
An interview does not authorize file edits. After agreement, use the appropriate
language writing skill if the requested writing work is authorized.

Evaluate purpose and scope, evidence, substantive alternatives, decided versus
open questions, and verifiability. Score applicable items 0, 1, or 2, normalize
to 10, and explain exclusions. Require 8/10 and verified requirements,
authorization, security, data safety, confirmed contracts, and stage evidence.
Correct failures and reevaluate at most three times; never repeat unchanged.
If still blocked, report each score, mandatory conditions, evidence, and
remaining blockers. Wait for required user decisions, access, or permission.
