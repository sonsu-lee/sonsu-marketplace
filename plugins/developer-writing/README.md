# Developer Writing

개발자 블로그, 기술 아티클, TIL, 디버깅 회고와 기술 선택 글만 소유하는 `1.0.0` capability pack이다.
일반 업무 문서, README, 티켓·PR 문구와 한국어·영어 교정은 host 기본 동작이나 해당 artifact
owner가 담당한다.

`write-developer-blog`는 `plan | draft | revise | audit` 모드를 구분하고 본문 전에 독자 문제,
핵심 답, 절 순서, 절별 근거와 한계를 흐름 의사코드로 고정한다. 저자의 1인칭 경험·감정·동기를
코드나 외부 자료에서 추론하지 않는다. 기술 주장은 repository 자료, 현재 host의 조사 도구와
직접 검증 결과에 연결하며 다른 marketplace plugin 설치를 가정하지 않는다.

파일 생성, 게시, Git 작업, 운영 환경 접근과 원격 mutation은 글 작성 요청에 포함되지 않는다.

포함 skill과 reference:

- `skills/write-developer-blog/SKILL.md`
- `skills/write-developer-blog/references/article-shapes.md`
- `skills/write-developer-blog/references/technical-evidence.md`

출처 경계는 [UPSTREAM.md](UPSTREAM.md)를 확인한다.
