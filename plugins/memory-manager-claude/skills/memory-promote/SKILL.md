# Memory Promote

현재 범위의 메모리와 원래 출처를 `search`/`get`으로 읽고, 서로 독립적인 반복 사례가 최소
두 개 있는지 확인한다. 같은 대화에서 복제된 기록 둘은 반복 사례가 아니다. 사용자 요청의
목적·입력·출력·예외·검증을 분리해 절차 후보를 만든다.
서로 다른 프로젝트를 사용자가 정확히 지정했다면 각 프로젝트 디렉터리에서 별도로 조회하고,
범위를 섞어 한 프로젝트의 기억으로 다시 저장하지 않는다.

결과는 **검토용 초안**으로 제시한다. 주장, 출처 ID, 일반화한 단계, 적용하지 않을 조건,
불확실성을 포함한다. 사용자 검토 전에는 스킬 경로에 파일을 만들거나 설치·자동 호출하지
않는다. 기존 기억을 삭제하거나 상태를 바꾸지 않는다. 절차화할 근거가 부족하면 부족한
사례를 명시한다.
