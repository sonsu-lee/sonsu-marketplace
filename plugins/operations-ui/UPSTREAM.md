# Reference provenance

이 플러그인은 외부 UI 코드나 asset을 복사하지 않았습니다. 운영형 화면의 공통 구조를 확인하기 위해 다음 공개 제품 자료를 참고했습니다. 특정 제품의 style token을 복제하거나 이 플러그인의 고정 테마로 만들지 않습니다.

- [Onfleet product](https://onfleet.com/product)
- [ClickPost NDR management](https://www.clickpost.ai/ndr-management)
- [LogiNext platform](https://loginextsolutions.com/)
- [Locus logistics solutions](https://locus.sh/)
- [Fluent Commerce order management](https://fluentcommerce.com/order-management-system/)
- [Extensiv warehouse management](https://www.extensiv.com/warehouse-management-system)
- [Logiwa warehouse management](https://www.logiwa.com/)

공식 Figma 기능을 사용하는 선택형 흐름은 설치된 Figma 플러그인의 현재 prerequisite와 capability 계약을 따릅니다.

2026-09-11에는 designbywani의 [정렬·간격·강약](https://www.instagram.com/reel/Dc3CXUjzjSp/),
[텍스트 역할](https://www.instagram.com/reel/Dck-Ch6TP3g/),
[중첩 카드 모서리](https://www.instagram.com/reel/DdEBHpTT_ys/) 릴스 캡션을 참고해 기존 `design.md`의
정보 관계·타이포그래피·형태 설명을 구체화했습니다. 캡션과 관찰 가능한 영상 화면 범위의 참고이며,
외부 화면 스타일·문장·asset을 가져오지 않았습니다. 해당 practitioner 사례는 차단 규칙이 아니라
제품 디자인 시스템과 실제 사용자 과업에서 다시 검증할 참고입니다.

간격의 해석은 [Atlassian spacing](https://atlassian.design/foundations/spacing/), 텍스트 대비는
[WCAG contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)와 대조했습니다.

2026-09-17부터 [공통 source map](references/design-quality-sources.md)의 ISO, WCAG, W3C
internationalization, Apple HIG, Nielsen usability와 Toss 공개 사례를 DQ0–DQ8 계약으로 사용합니다.
Madia Designer 공개 영상은 [별도 연구 카탈로그](../../docs/research/madia-design-practice-catalog.md)에서
timestamped evidence와 승격 조건을 충족한 뒤에만 규칙 후보가 됩니다.
