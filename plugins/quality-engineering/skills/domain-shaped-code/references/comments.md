# Comment policy

주석은 코드 자체로 분명하게 표현할 수 없는 이유, 불변식, trade-off 또는 외부 제약을 설명한다.

## Keep

- 비직관적인 순서나 계산이 필요한 이유
- 호출 전후에 반드시 성립해야 하지만 타입으로 표현하기 어려운 불변식
- 외부 protocol, browser, database 또는 compatibility 제약
- 안전해 보이는 변경이 왜 위험한지 설명하는 짧은 경고
- 후속 작업에 필요한 구체적인 조건과 추적 가능한 issue

## Remove or rewrite

- 바로 아래 코드가 무엇을 하는지 그대로 읽어 주는 주석
- 이미 틀렸거나 코드 변경으로 검증되지 않는 설명
- 작성 과정, 대화 또는 임시 결정을 남긴 서술
- 근거 없는 "혹시 몰라서", "미래를 위해" 같은 추측
- 좋은 이름이나 작은 함수로 더 정확하게 표현할 수 있는 설명

주석이 필요한 이유가 복잡한 코드 구조 때문이면 먼저 구조를 단순화할 수 있는지 확인한다.
