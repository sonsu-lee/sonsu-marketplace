# 그래픽 디자인하기

> 영문 정본: [SKILL.md](SKILL.md) (`10e9691` 기준 번역).
> 사람이 읽기 위한 번역본이며 에이전트는 이 파일을 읽지 않는다.

그래픽의 용도와 전달 방식에 맞게 디자인하거나 개선한다. 허용된 범위를 지키고
실제로 관찰한 결과만 보고한다.

## 워크플로

1. **브리프 파악.** 목적, 대상, 기존 아이덴티티, 기준 에셋, 편집 가능한 형식,
   출력과 재현 제약을 확인한다. 변경이 허용되지 않았다면 제공된 비율, 의미 있는
   콘텐츠, 필요한 편집 가능성, 기존 처리 방식을 유지한다. 필요한 변경은 제안하고
   채택 여부를 묻는다. 이는 범위 결정이지 승인 절차가 아니다. 승인이나 제작
   요건을 지어내지 않는다.
2. **용도에 맞게 디자인.** 아이콘은 무게, 모서리, 실루엣을 패밀리 전체로 판단하고
   실제 크기와 렌더러에서 내보낸 결과를 점검한다. 뭉개지는 세부는 단순화하되
   의미는 유지한다. 일러스트와 아이덴티티는 브리프와 실제 용도에 맞춘다. 이후
   편집이나 비교에 필요한 표현을 파괴하기 전에 적절한 이전 상태를 보존한다. 실제
   재현 제약으로 변형이 필요하면 락업 전체를 고려하고 풀컬러 원본을 유지한다.
3. **점검과 보고.** 사용 가능한 출력을 맥락 속에서 점검하고 실제로 렌더링하고
   확인하고 전달한 것을 보고한다. 없는 에셋과 렌더링 또는 제작 증거를 밝힌다.

## 조건부 연구

아이콘 구성, 렌더링, 그래픽 인코딩, 편집 단계, 재현 변형, 마스터와 미리보기
전달에 연구 맥락이 필요하면 [그래픽 크래프트와 핸드오프](references/craft.md)를
읽는다. 보편적인 레시피나 측정된 결과가 아닌 조건부 가이드다.

## 주의할 점

- 승인 상태와 책임은 프로젝트 사실이며 파일이나 테스트의 부재로 판단하지 않는다.
  제공되지 않았다면 알 수 없는 상태로 두고 미승인, 아직 승인되지 않음, 미정으로
  바꾸거나 승인을 필수 단계로 규정하지 않는다. 승인이 필요한지, 누가 승인하는지
  확인하도록 조언한다.
- 미리보기를 편집 가능한 마스터로 가정하지 않는다. 벡터 캔버스나 정지
  미리보기만으로 제조 가능성, 색상 정확성, 승인을 입증할 수 없다.
- 모든 물리 매체가 그라디언트를 금하는 것은 아니다.

## 선택 사항: omp 엄격 실행

Codex와 Claude Code는 가이드만 받으며 omp의 강제 기능은 받지 않는다. omp에서는 운영자가
`/design-start <plan-json-path>`를 호출하고 계획을 확인하기 전까지 엄격 모드가 휴면 상태로 유지된다. 계획에는 모드
`graphics`(캡처, 점검, 편집 없이 조언만 할 때는 `advisory`), 워크스페이스 기준의 정확한 상대 경로, 목표, 원래 요청,
확인된 프로젝트 사실, 시각 캡처, 승인된 점검 실행 파일과 argv가 들어간다. 직접 시작하거나 승인하지 않는다. 캡처 어댑터는 승인된
HTML/SVG 파일이나 루프백 웹 대상을 지원하며 임의의 네이티브 편집기 문서는 지원하지 않는다. 필요한 증거를 캡처할 수 없다면 관련 없는
이미지로 대체하지 말고 그 한계를 보고한다.

활성 상태에서는 범위 안에서 `design_status`, `design_read`, `design_write`,
`design_capture`, 선언된 `design_check` 작업을 사용한다. 증거가 준비되면
멈추고, 운영자에게 `/design-report`를 실행한 다음 `/design-accept`로 보고서를
그대로 게시해 달라고 요청한다. `/design-report`는 대화 밖에서 최종 보고서를
작성하고 사실을 검증한다. 영수증은 작업을 기록할 뿐, 디자인 품질이나 제작
승인을 기록하지 않는다. 작업을 진행할
수 없거나 증거가 없으면 운영자에게 `/design-stop`, `/design-blocked reason`,
`/design-limited reason`을 사용해 달라고 요청한다. 이들은 성공이 아닌 종료 방식이다. 스스로 수락하거나 증거를 지어내지
않는다. 이 프로세스 내 확장은 OS 샌드박스가 아니며, 승인된 점검은 프로세스를 실행한다. 공식 결과는 게시된 보고서이며 당신의 서술이
아니다.
