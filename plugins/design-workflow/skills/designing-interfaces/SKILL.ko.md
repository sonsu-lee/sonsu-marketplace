# 인터페이스 디자인하기

> 영문 정본: [SKILL.md](SKILL.md) (`6ebbde0` 기준 번역).
> 사람이 읽기 위한 번역본이며 에이전트는 이 파일을 읽지 않는다.

사용자의 목표, 대상, 관련 제약, 기존 디자인 시스템, 의도한 산출물을 파악한다. 변경하기 전에 기존 인터페이스와 실제 콘텐츠를 점검한다.
요구 사항, 기능, 의미 있는 콘텐츠와 상태(오류, 빈 상태, 복구 경로 포함)를 유지한다. 구성을 깔끔하게 보이게 하려고 기능을 제거하거나
정책을 지어내지 않는다. 해법을 실질적으로 바꾸는 불확실한 부분을 밝힌다.

사용자의 작업에서 계층 구조를 고른 다음, 실제 콘텐츠를 중심으로 읽기 쉬운 그룹, 컨트롤, 반응형 배치를 구성한다. 무엇이 고정되고, 크기가
바뀌고, 재배치되는지 명시하고, 중간 너비도 고려한다. 상태와 행동 레이블은 실제 동작과 맞게 설계하며, 시스템이 확인하기 전에 성공했다고
표시하지 않는다. 키보드, 접근 가능한 이름, 대비는 눈대중이 아니라 해당 프로젝트 요건과 적절한 도구로 점검한다. 모든 경우에 맞는 고정된
글꼴이나 간격 수치는 없다.

실제 에셋을 포함해 관련 대상 크기와 상태에서 결과를 점검한다. 브라우저나 필요한 상태를 사용할 수 없다면 시각 검증을 했다고 주장하지 말고 그
한계를 보고한다. 관찰과 제안을 구분하고, 의미 있는 변경과 수행한 점검을 나열하며, 해결되지 않은 트레이드오프를 밝힌다.

## 조건부 연구

디자인 결정에 맞는 것만 읽는다. 타이포그래피, 간격, 이미지, 아이콘, 시각적 인코딩은 [시각 판단](references/visual.md),
반응형 동작, 컨트롤, 상태, 서비스 정책, 디자인 근거는 [흐름 판단](references/flows.md), 편집 가능한 산출물, 상충하는
레퍼런스, 파괴적 편집, 제작 핸드오프가 관련될 때는 [핸드오프 워크플로](references/handoff.md), 애니메이션을 추가, 변경,
제거할 때는 [모션](references/motion.md), 웹 인터페이스를 휴대폰이나 태블릿에서 쓸 때는
[터치 기기의 웹](references/web-touch-platform.md)을 본다. 이 문서들은 맥락에 따른 휴리스틱이며, 보편적인 규칙도
사용자 결과의 증거도 아니다.

## 선택 사항: omp 엄격 실행

이식 가능한 스킬만으로는 가이드일 뿐 강제가 아니다. Codex와 Claude Code는 omp 확장의 제어 기능을 갖추지 못한다. omp에서는
운영자가 명시적으로 `/design-start <plan-json-path>`를 호출하고 표시된 계획을 확인하기 전까지 엄격 모드가 휴면 상태로
유지된다. 계획에는 모드 `design`(캡처, 점검, 편집 없는 제안은 `advisory`), 워크스페이스 기준의 정확한 상대 파일 경로,
목표, 원래 요청, 확인된 프로젝트 사실, 캡처 대상/뷰포트/시나리오, 승인된 점검 실행 파일과 argv가 들어간다. 시각 작업에는 캡처가
필요하다. 운영자를 대신해 계획을 시작, 승인, 변경하지 않는다.

활성 상태가 되면 승인된 범위에서 `design_status`, `design_read`, `design_write`,
`design_capture`, 선언된 `design_check` 작업을 사용한다. 새 증거가 생기면
멈추고, 운영자에게 `/design-report`를 실행한 다음 `/design-accept`로 보고서를
그대로 게시해 달라고 요청한다. `/design-report`는 대화 밖에서 최종 보고서를
작성하고 사실을 검증한다. 영수증은 기록된 작업만 증명하며, 시각적 품질이나
준수 여부는 증명하지 않는다. 캡처나
점검을 수행할 수 없거나 범위를 바꿔야 한다면 걸림돌을 설명하고 운영자에게 `/design-stop`,
`/design-blocked reason`, `/design-limited reason`을 사용해 달라고 요청한다. 이들은 성공이 아닌 종료
방식이다. 증거를 지어내거나, 스스로 수락하거나, 게이트를 우회하지 않는다. 이 확장은 프로세스 내에서 실행되며 OS 샌드박스가 아니고, 승인된
점검은 샌드박스되지 않은 프로세스 실행이다. 공식 결과는 게시된 보고서이며 어시스턴트의 서술이 아니다.
