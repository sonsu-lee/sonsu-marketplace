# 조건부 비평 증거

> 영문 정본: [evidence.md](evidence.md) (`0c90a4a` 기준 번역).
> 사람이 읽기 위한 번역본이며 에이전트는 이 파일을 읽지 않는다.

요청받은 비평에 연구 맥락이 필요할 때 해당 절을 사용한다. 이 관찰들은 검토한 출처 구절과 표본 프레임에서 나온 것이며, 측정된 사용자
결과도, 검토 대상 산출물에 대한 독립적인 검증도 아니다. 출처는 하나의 판단을 보여 줄 뿐이며, 발견은 현재의 산출물이 뒷받침해야 한다.

## 시각 판단

강조를 사용자의 실제 작업과 필요한 정보에 견주어 비교한다. 보기 좋지 않은 배치가 자동으로 기능상 결함인 것은 아니며, 계층 구조가 어떤
행동이나 콘텐츠를 가리는지 설명한다. P01은
[211–303초](https://www.youtube.com/watch?v=ZT1UZQCTj_U&t=211s)에서 설명된다.

아이콘 패밀리는 따로 떨어진 글리프에 단일한 구성 규칙을 강요하지 말고 함께 평가한다. 작은 채움 세부도 윤곽선 패밀리와 일관될 수 있다.
P07 출처의 372초 샘플에는 이런 세부가 남아 있고 294초 샘플에는 패밀리 비교가 나오며, 관련 내레이션 구간은
[363.58–387.029초](https://www.youtube.com/watch?v=i8jG_5iKELI&t=363s)이다. 이는 현재
사용자에게 알아보기 쉽다는 것을 확립하지 않는다.

대비에 관한 주장이라면 실제 전경, 표면, 텍스트 분류를 확인하고 해당 표준에 따라 측정한다. 겉모습에서 적합성을 추정하지 않으며, 출처의 예시
값을 보편적인 규칙으로 바꾸지 않는다. P20의 출처 맥락은
[58–134초](https://www.youtube.com/watch?v=8sMNvinRLu0&t=58s)이다.

## 흐름과 상태 판단

무엇이 고정되고, 크기가 바뀌고, 재배치되는지 구분한다. 양 끝 스크린샷 두 장으로는 중간 동작이 확립되지 않으며, 필요한 콘텐츠를 숨기는 것은
반응형 해법이 아니다. P16–P18의 출처 맥락은
[91–138초](https://www.youtube.com/watch?v=jaI2E50wu2k&t=91s),
[138–258초](https://www.youtube.com/watch?v=jaI2E50wu2k&t=138s),
[264–348초](https://www.youtube.com/watch?v=jaI2E50wu2k&t=264s)이다. 관찰하지 못한 전환은
실행해 보았다고 주장하지 말고 관찰하지 못했다고 보고한다.

선택, 현재 상태, 가능한 행동을 구별한다. 표시된 종속 선택지를 지우라고 권하기 전에, 그것이 계속 호환되는지 확인한다. P28의 맥락은
[207–249초](https://www.youtube.com/watch?v=iHqhtvWn_0s&t=207s)와
[393–440초](https://www.youtube.com/watch?v=iHqhtvWn_0s&t=393s)이다. 비활성화된 컨트롤이나
일반적인 오류는 설명이나 복구에 대한 우려를 뒷받침할 수 있지만, 보이지 않는 백엔드 정책을 드러내거나 요청이 깨졌음을 증명하지는 않는다.

진행 상황과 출처를 올바른 응답과 상태에 연결한다. 렌더링된 성공 레이블은 시스템이 실제로 성공했다는 증거가 아니다. P32의 맥락은
[687–790초](https://www.youtube.com/watch?v=ENIvZFD9iLM&t=687s)이다. 알림 기록이 비어 있을
때는 실제 보존 규칙과 데이터가 없는 경우를 구분한다. P48의 [486.39–512.27초
구절](https://www.youtube.com/watch?v=Hzt7nv2ZBuo&t=486s)과 496초 샘플은 보존/삭제를 설명하는
문구를 보여 줄 뿐, 그것이 실제로 적용된다거나 이해도가 측정되었음을 보여 주지는 않는다.

## 상충하는 레퍼런스와 핸드오프

개정 때문에 레퍼런스들이 일관되지 않다면 승인된 변경과 그 담당자를 확인한 뒤 무엇을 동기화해야 하는지 식별한다. 그래도 실제 산출물이
뒷받침하는 결함은 보고한다. 오래된 레퍼런스가 있다고 해서 모든 차이가 결함이 되지는 않는다. W02는
[978.24–1029.189초](https://www.youtube.com/watch?v=9_ZOANs_UcU&t=978s)의 인터뷰
일화이며, 감사를 거친 사고도 관찰된 문서 갱신도 아니다. 읽기 전용 리뷰에서는 수정하거나 승인 위계를 지어내지 말고 수정을 권고한다.

주장하는 개선을 제시된 문제에서 실제 디자인 선택과 확보된 증거까지 추적한다. P46의 맥락은
[966.36–1017.91초](https://www.youtube.com/watch?v=-Jzn4PnTmoU&t=966s)이다. 서사만으로
전환, 사용성, 협업이 개선되었다고 주장하지 않으며, 이를 채용이나 경력 평가의 기준으로 바꾸지 않는다.
