# omp의 작업 연속성

여러 단계의 작업은 omp 순정 todo와 세션 기록으로 관리한다. 현재 목적, 승인된 범위, 끝난 작업, 다음 작업, 확인하지 못한 결과를 필요한 만큼 남긴다. 단발 작업이나 위임된 부분 작업에는 별도 기록을 만들지 않는다.

컴팩션이나 재개 뒤에는 최신 사용자 지시, 실제 산출물과 외부 상태를 확인한 뒤 이어 간다. 기록이나 todo의 완료 표시만으로 성공을 판단하지 않는다. 외부 작업의 결과가 불분명하면 같은 작업을 반복하기 전에 대상을 다시 읽는다.

이 패키지는 독자 checkpoint, `.sonsu` 아래의 기록, Git exclude, 세션 hook, extension을 만들거나 갱신하지 않는다. 기존 기록은 삭제하거나 이전하지 않는다. 순정 todo를 쓸 수 없을 때도 대화에서 확인한 상태와 다음 작업을 명시하고, 독자 저장 위치를 추가하지 않는다.

작업 연속성은 실행 권한을 추가하지 않는다. 읽기 전용 요청은 읽기 전용으로 유지하고, commit, push, PR·티켓 생성과 갱신 등은 각 스킬의 권한 조건과 현재 사용자 지시를 따른다. 디자인 품질 산출물과 검증은 작업 연속성 기록과 별개로 해당 스킬의 계약을 따른다.
