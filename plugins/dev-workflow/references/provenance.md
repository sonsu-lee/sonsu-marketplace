# 설계와 계획의 출처 표기

선택과 판단의 근거에는 출처 종류와 실제로 찾을 수 있는 위치를 붙인다.

| 태그 | 기록할 내용 |
| --- | --- |
| `[사용자 결정]` | 사용자가 확정한 결정 |
| `[제공 자료: 대화 발췌 또는 파일 위치]` | 제공된 자료의 식별 가능한 발췌·위치 |
| `[저장소: 경로:줄]` | 읽은 코드·문서 위치 |
| `[공식문서: URL]` | 적용 버전의 공식 계약 |
| `[실험: 명령 → 관찰 결과]` | 실행한 명령과 실제 결과 |
| `[논문/실무자: URL]` | 외부 연구·실무 근거 |

고정 locator가 없는 자료는 그 한계를 밝힌다. 태그는 출처를 나타내며 검증·대표성·합의·승인 여부는 별도로 판단한다. 인터뷰·피드백은 제공 자료로 기록하고 사용자 결정과 구분한다. 위치는 실제 확인한 값만 쓴다.

근거가 없는 판단은 `[추론]`으로 표시하고 확정 결정의 근거에서 제외한다. 결정에 꼭 필요한 추론은 조회·실험으로 확인하거나 미결정 항목으로 남긴다.

예: `[저장소: src/export.ts:42]`에서 스트림 종료를 확인했다면 해당 경로의 근거로 쓴다. 사용자가 제공한 운영자 의견은 `[제공 자료: 대화의 운영자 의견]`으로 기록하고 제품 변경 승인과 구분한다.
