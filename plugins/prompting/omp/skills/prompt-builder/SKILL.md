# 프롬프트 작성

사용자가 의도한 결과와 제약을 보존하는 가장 작은 프롬프트를 작성한다. 대상 제품의 입력 칸에 바로 붙여 넣을 수 있는 산출물을 제공한다.

## 절차

1. 사용자가 명시한 모델·제품·독자·언어·역할·원본 자료·출력 형식을 확인한다. 종류가 지정되지 않았다면 현재 chat surface에서 한 번 사용할 user prompt 또는 task prompt로 정한다. 산출물을 실질적으로 바꾸는 누락 정보만 하나의 집중된 질문으로 확인하고, 그 답에 의존하는 부분만 보류한다. 독립적인 부분은 완성하고 나머지는 안전한 기본값을 사용하되 사용 방법에 영향을 주는 가정만 밝힌다.
2. 대상에 따라 [OpenAI 지침](references/openai-prompt-guidance.md) 또는 [Claude 지침](references/claude-prompt-guidance.md)을 읽는다. 최신·현재 권고가 필요하면 해당 제공자의 공식 문서를 확인한다. 모델 선택이 필요할 때만 [Codex 프로필](../../references/model-profiles.md) 또는 [Claude 프로필](../../references/claude-model-profiles.md)을 참조한다.
3. 원하는 결과부터 쓴다. 단순한 작업은 한 문장이나 짧은 문단으로, 복잡한 작업은 역할 → 목표 → 맥락 → 성공 기준 → 제약 → 도구와 권한 → 출력 → 중단 규칙 중 동작을 바꾸는 섹션만 사용한다. 경로 자체가 요구사항일 때만 단계를 지정하고, 나머지는 성공 상태를 설명해 모델이 경로를 선택하게 한다.
4. 안정적인 재사용 지시는 동적 데이터보다 앞에 두고, 길거나 신뢰할 수 없는 자료는 Markdown 섹션이나 XML tag로 구분한다. 사실·권한·도구·모델 capability·business rule은 확인된 범위만 쓴다. `must`, `never`, `always`, `only`는 실제 불변 조건에 사용한다. 지원되는 API control은 본문과 분리한다.
5. 요청한 언어로 명확하게 쓴다. 영어는 행위자·동작·대상·조건을 분명히 하고 직접적인 동사와 익숙한 표현을 쓴다. 선택 조건은 해당 동작 앞에 놓고, 같은 개념에는 같은 용어를 사용한다. 정확한 제품·interface·코드 이름과 근거·불확실성·예외·의미 있는 수동태를 보존한다. 사실·기준·관계를 더하지 않는 장식 표현은 덜어 낸다.
6. 중복 지시 → 측정 가능한 요구를 더하지 않는 일반 문구(`think step by step`, `be thorough`, `be concise` 등) → 쓰지 않는 제목·빈 placeholder → 작업을 바꾸지 않는 배경 → 모호함이나 필수 동작을 설명하지 않는 예시 순서로 줄인다. 안전 제한·권한 경계·성공 기준·필수 근거·검증·중요한 제한사항은 남긴다.
7. 아래 결과 형식으로 묶고 각 복사 단위가 추가 편집 없이 해당 입력 칸에서 완결되는지 확인한다. 필수 입력·복사 가능한 API 설정, 닫힌 fence와 내부 code block을 점검한다. template 요청일 때만 미작성 placeholder를 남긴다. 맞지 않으면 산출물을 고쳐 다시 확인하고 점검 과정은 내부에 둔다.

## 결과

응답은 복사 가능한 산출물로 시작한다.

- 단일 입력 칸: 완전한 프롬프트 하나를 첫 요소인 fenced block 하나에 담는다. 모델에 입력할 역할·맥락·제약·출력 형식까지 같은 복사 단위에 넣는다.
- 여러 입력 칸 또는 역할별 분리 요청: 입력 칸마다 이름을 바로 앞에 표시하고 각각 fenced block으로 반환한다.
- 실행에 필수인 reasoning effort·verbosity·Structured Outputs 등 API control: 대상 surface의 정확한 설정 이름·형식으로 별도 fenced block에 담는다.

바깥 fence는 최소 3개의 backtick을 쓰며 내부의 가장 긴 backtick 연속보다 길게 만든다. 목록·인용문 밖의 줄 첫 칸에서 열고 닫는다. 모델 선택·복사할 수 없는 UI 설정·가정이 사용 방법에 영향을 줄 때만 산출물 뒤에 짧은 불릿을 최대 3개 붙인다. 프롬프트만 요청받으면 산출물만 반환한다.

## 예시

입력: “ChatGPT에 넣을 한국어 요청을 만들어 줘. 다음 메모를 행사 안내 한 문장으로 바꾸고 싶어. 메모: 북클럽은 목요일 오후 7시 도서관 2층에서 열린다.”

결과:

```text
다음 메모의 사실만 사용해 한국어 행사 안내 한 문장을 써 줘. 안내문만 반환해 줘.
메모: 북클럽은 목요일 오후 7시 도서관 2층에서 열린다.
```

같은 내용을 OpenAI Responses API의 두 입력 칸으로 요청했다면 다음처럼 나눈다.

`instructions`
```text
제공된 메모의 사실만 사용해 한국어 행사 안내 한 문장을 쓴다. 안내문만 반환한다.
```

`input`
```text
북클럽은 목요일 오후 7시 도서관 2층에서 열린다.
```

## 참고 자료
