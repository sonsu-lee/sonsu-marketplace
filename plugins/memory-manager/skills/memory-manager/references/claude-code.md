# Claude Code 메모리 접근

Claude Code의 기존 auto memory를 대상으로 할 때만 읽는다. 이 스킬의 메모리 점검·정리는
Claude Code에서 실행할 수 있지만, plugin 설치나 Claude Code 설정 변경은 그 작업에 포함하지 않는다.

## 대상 디렉터리

사용자가 명시한 경로나 현재 Claude Code 호스트가 알려 준 memory directory를 우선한다.
기본 형태는 `~/.claude/projects/<project>/memory/`지만 `<project>`를 현재 폴더의 basename이나
문자 치환만으로 확정하지 않는다. 공식 문서상 같은 저장소의 worktree는 메모리를 공유할 수 있고
`autoMemoryDirectory` 설정으로 위치를 바꿀 수 있다. 필요한 설정 항목과 실제 디렉터리만 확인해
저장소와의 대응을 검증한다. 여러 후보가 남으면 사용자에게 경로를 확인한다.

`CLAUDE.md`, `CLAUDE.local.md`와 rules 파일은 auto memory와 다른 지시 표면이다.
메모리 정리 요청만으로 이 파일들을 편집하지 않는다. 옮기는 편이 나은 규칙은 제안으로 남긴다.

## 인덱스와 주제 파일

현재 형식을 확인해 `MEMORY.md`와 연결된 주제 파일을 읽는다. 공개 문서는 시작 시 인덱스의
첫 200줄 또는 25KB를 불러오고 주제 파일은 필요할 때 읽는다고 설명한다. 이 값은 Claude Code용
확인 기준이며 Codex에 적용하지 않는다. 설치 버전이나 현재 호스트가 다른 한도를 제시하면
그 계약을 우선한다.

인덱스를 간결하게 유지하고 세부 내용은 주제 파일로 연결하되, 기존 frontmatter·유형·검색
방식을 보존한다. 이번 변경에서 확인하지 않은 형식을 전체 파일에 강제하거나 모든 주제 파일이
반드시 인덱스에 직접 연결돼야 한다고 가정하지 않는다.

직접 편집은 사용자 요청과 현재 호스트에서 허용된 경우에만 본문의 절차로 수행한다. 공유
메모리를 다른 Claude 세션이 쓰고 있을 수 있으므로 변경 직전 상태를 대조한다. raw transcript는
필요한 주장을 확인할 때만 좁게 검색하고 수정하지 않는다. 별도 cold-storage나 Git commit을
정리 작업의 필수 단계로 추가하지 않는다.

출처: [Claude Code 메모리 공식 문서](https://code.claude.com/docs/en/memory), 2026-09-07 확인.
현재 동작이나 설정 지원을 묻는 경우 이 날짜의 설명만으로 확정하지 않고 공식 문서와 실제
호스트를 다시 확인한다.
